Ebala 0.53 — проверочная сборка Windows x64, 04.11.2026

ОСНОВА
- Ebala 0.52 и последовательная переработка Excel на этапах 1–11.
- Архитектура из PROJECT.md не изменена: Word использует ядро Go;
  Excel рассчитывает по редактируемым исходным данным и формулам,
  за оговорёнными исключениями для численного поиска положения кранов.

ИЗМЕНЕНИЯ ЭТАПА 12
- Исправлен устаревший регрессионный тест многопролётного Excel:
  теперь он проверяет ISNUMBER(A5),ISNUMBER(B5), поскольку нулевая
  координата x=0 является корректной расчётной точкой.
- Приложению присвоена версия 0.53, обновлены скрипт сборки и справка.
- Добавлен независимый OOXML-сканер Verification/Phase12/check_xlsx_xml.py.
- Подготовлена проверочная Windows x64 GUI-сборка (без консоли).

ФАКТИЧЕСКИ ВЫПОЛНЕНО
- Linux Go 1.23.2: GO111MODULE=off go test -count=1 -timeout=300s — PASS (133,116 с).
- Формирование 15 XLSX — PASS (TestExcelPhase10Fixture, TestExcelPhase11Fixtures).
- OOXML: 15 книг, 303 листа, 523790 формульных ячеек, 88 диаграмм,
  356 ссылок диаграмм. Ошибок структуры и ссылок в проверенной выборке не найдено.
- GOOS=windows GOARCH=amd64 CGO_ENABLED=0 GO111MODULE=off go build
  -trimpath -ldflags="-H=windowsgui -s -w" — PASS.
- PE x64, Optional Header PE32+, Subsystem 2 (Windows GUI) — подтверждено.

НЕ ВЫПОЛНЕНО / ОСТАЁТСЯ
- На настоящей Windows интерфейс не запускался.
- В Microsoft Excel контрольные книги не открывались и численно не пересчитывались.
- Полная численная поверка Б.15а, гололёда, больших куполов и сложных
  соседних фонарей остаётся открытым пунктом.
- Независимый движок, использованный на этапе 11, не удалось повторно
  запустить на этапе 12. 64/64 совпадений — результаты именно этапа 11.
- Все 41 критерия приёмки Excel нельзя считать закрытыми.

ПОСТАВКА
- Ebala_0.53_Windows.zip — EXE и локальные каталоги ресурсов.
- Ebala_0.53_Sources.zip — весь Go-код, тесты, базы, карты и QA.
- Пользовательские карты в самостоятельно выбранной внешней папке не
  заменяются и не удаляются. Встроенная Maps содержит справочные TSV;
  внешние графические карты СП в этот архив не добавлялись.
