Ebala 0.46 — изменения и результаты проверок
Дата: 03.11.2026

ВЫПОЛНЕНО
1. Шедовые покрытия (Б.4, рисунок Б.7): включён расчёт двух вариантов,
   равномерного μ=1,0 и неравномерного с μ=1,4/0,6 по половинам каждого пролёта.
   Входные параметры: длина пролёта, число пролётов, ширина покрытия,
   высота конька H над землёй. H не входит в μ для стандартного случая Б.4,
   но сохраняется в геометрии и проекте. Экспорт Word/Excel и ведомость.
2. Покрытия с парапетами (Б.13, рисунок Б.16): отдельная схема со своей
   геометрией; обычный случай μ=1,0, местный снегозанос при h>S0/2:
   μmax=min(2h/S0,3), ширина b=2h, линейное снижение до μ=1,0.
   Линейная эпюра представлена 64 консервативными интервалами с
   точным μmax у парапета. Для плоских широких покрытий или парапета
   выше 1,2 м сформирован отдельный проверочный случай по Б.8.
   Экспорт Word/Excel и сохранение в общую ведомость.
3. Для продольного фонаря, закрытого сверху, при плоских скатах шириной
   b>24 м дополнительно рассчитываются две независимые проверки
   местного снегозаноса по модели Б.8 (без сложения альтернатив).
4. Для сферической и конической кровли на вкладке результатов
   исходные полные рисунки Б.14/Б.15 СП размещены слева на всю
   доступную высоту с заголовком «Схема-пояснение из СП»,
   расчётные варианты и эпюры — справа.
5. Исправлено отображение прозрачных PNG через Windows GDI:
   пиксели компонуются с белой подложкой, чтобы не возникал чёрный фон.
6. Утверждённая геометрическая схема шедовых покрытий сохранена
   неизменной, добавлена отдельная геометрическая схема парапета.

НЕ ВЫПОЛНЕНО / ОГРАНИЧЕНИЯ
- Полная самостоятельная динамическая модель сноса снега на высотных
  шедовых покрытиях по специальным условиям не реализована. H сохранена,
  автоматическая корректировка μ по H не вводилась.
- Эпюры снегозаноса парапета дискретизированы, а не являются
  аналитической непрерывной линией в пользовательском интерфейсе.
- Полный пересмотр всех снеговых схем приложения Б не входил в этот выпуск.
- Самостоятельный ветер, фонари открытые сверху, зенитные фонари,
  совместимость с Windows 7 по согласованию отложены.
- Запуск GUI в настоящей Windows и открытие в настольных версиях
  Microsoft Word/Excel не проводились в этой среде.

ПРОВЕРКИ
- Регрессионные Go-тесты, включая шедовые покрытия, парапеты,
  формирование DOCX/XLSX и дополнительные варианты у фонарей.
- Сборка Windows x64 с PE Subsystem=2 (Windows GUI, без консоли).
- Проверка целостности ZIP-архивов.
