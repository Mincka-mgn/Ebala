Ebala 0.32 — снеговые нагрузки: два независимых пролёта, купольные резервуары, табличный Word.

1. Для обычных плоских, односкатных, двускатных и сводчатых кровель добавлен правый независимый пролёт. По умолчанию — «Нет», поля отключены. Пользователь задаёт тип, L2, уклон/подъём и отметку кромки. Две кровли рассчитываются в одной схеме, при перепаде добавляется отдельный вариант снегозаноса по Б.8 СП 20.13330.2016.
2. Старый режим однотипных многопролётных покрытий оставлен отдельным шаблоном.
3. Для сферического купола с f/D>0,05 реализованы пространственные варианты 2 по Б.11 и 3 по Б.11 при подтверждённых препятствиях, повышенной шероховатости или защите от ветра. В Excel приведены полярные расчётные таблицы. Ветровое снижение по п.10.8 не применяется к пространственной эпюре (консервативно ce=1).
4. Для αмакс≥60° у сферического купола сохраняется ограничение: СП 20 не регламентирует обычный набор вариантов 2–3. Программа сообщает о необходимости отдельного обоснования, вместо выдумывания коэффициентов.
5. Word: геометрия перед таблицей исходных размеров, рисунок 3 см по высоте; заголовки связаны с последующими объектами; основные расчёты и пояснения представлены таблицами; варианты идут с эпюрами сразу после таблиц численных значений, без отдельного раздела итоговых эпюр.
6. Для резервуаров раскрыты расчётные формулы куполов (Б.10, Б.11) и конусов (Б.12, Б.13). Для двух независимых пролётов предусмотрены отдельные пояснения расчётных схем.
7. Excel: для сферических крыш добавлены формулы пространственного распределения, в том числе на полярных листах.
8. Сохранены пользовательские SVG и PNG в Resources/SnowRoofs, отчёты по-русски, архив программы без суффикса Program.

Проверка: Go-тесты, сборка amd64/Windows, пробные Word/Excel (две независимые кровли, конус, купол), рендеринг DOCX, открытие XLSX через LibreOffice.
Ограничения: для отдельных многопролётных схем Excel всё ещё опирается на нормативные значения μ расчётного ядра. Живой интерфейс под Windows здесь не проверялся. Для сферических куполов с αмакс≥60° автоматического расчёта нет. Переключатель единиц кПа/кгс/м² ещё не добавлен.
