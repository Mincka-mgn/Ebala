# Ebala 0.56, этап 1. Исправления расчётного ядра

**Дата:** 05.11.2026  
**База:** Ebala 0.55, `Ebala_0.55_Sources.zip`  
**Статус:** промежуточные исходники для дальнейшей разработки; **не выпуск Windows-программы**.

## 1. Реализовано

### Снеговая схема Б.8, перепады высот

- В условиях образования местного снегозаноса и формулах ограничений коэффициента формы используется `S₀ = Sg`, без умножения на `ce` и `ct` (СП 20.13330.2016, п. 10.4 и приложение Б).
- Исправлены расчётное ядро (`snow.go`) и формулы связанных листов Excel (`snow_excel_v031.go`, `snow_excel_paired_step_phase7.go`).
- Добавлен контрольный пример: при `Sg = 2 кПа` перепад `h = 0,9 м` не образует местного снегозаноса ни при `ct=1`, ни при `ct=0,8`; порог находится на `h=1 м`.

### Снеговая схема Б.15а, сфера с конусом

**Временно исключена из выпадающего списка пользовательских схем.** Не выдаётся за завершённую нормативно принятую функцию. Исходный расчётный код сохранён для последующего возвращения, когда будет согласована окончательная интерпретация требований СП.

В экспериментальном коде:

- Угол `β` приведён к единому отсчёту от вертикали вниз: `0°` вниз, `90°` вправо, `180°` вверх, `270°` влево. Для каждой зоны нулевое направление **не переназначается**.
- Угловые границы: `30°`, `150°`, `210°`, `330°`.
- Зона 2 получает **половину радиальной эпюры** формулы Б.10, рассчитанной при `β=90°`, а не половину единственного максимального значения. На линиях `β=30°` и `150°` зона 2 непрерывно сопрягается с зоной 1.
- В зоне 6 для отрицательной синусоидальной ветви используется модуль синуса в рамках согласованной рабочей интерпретации; режим зоны 5 (принятая/буквальная формула) не удалён.
- `Cr1` рассчитывается по отдельной высоте гипотетической полной сферы, а не по общему подъёму конусно-сферического покрытия. В коде принят расчёт `fсферы=(D/2)*tan(α1/2)` для сферы одинакового диаметра и касательного угла на периферии. Это **предварительная геометрическая интерпретация для скрытого расчёта**, её окончательное нормативное обоснование остаётся предметом последующей проверки.
- Максимум коэффициента формы определяется отдельно от дискретизации полярной сетки, с проверкой расчётных критических радиусов; сетка теперь строится на полном угловом диапазоне.
- Согласованы вспомогательные формулы листа Excel и представление максимума в интерфейсных расчётных данных. Полная независимая приёмка всех формул Word/Excel для Б.15а **не выполнена**, поскольку схема скрыта.

### Предварительное исправление диаметра `D`

- При геометрии с `D ≤ 2r` попытка корректировки больше не отсекается обработчиком ввода; диаметр изменяется на стадии редактирования полей и показывается предупреждение.
- Внутренняя корректировка повторным вызовом не изменяет уже исправленное значение. Данное поведение подтверждено тестом функции обработки геометрии, но в живом GUI на Windows ещё не проверялось.

### Не изменялось

- **Расстановка мостовых кранов:** сохраняются фиксированная последовательность и её зеркальное рассмотрение для противоположной стороны пролёта. Претензии аудита к перестановкам сняты.
- Структура проекта и архитектура Go/Win32 остаются прежними.

## 2. Тесты и проверки

Запуск на исходниках: `GO111MODULE=off go test -v ./... -count=1`.

**Результат последнего полного прогона:** 275 тестовых случаев: 262 успешно, 13 пропущено, 0 ошибок. Итог `PASS`, 54,105 с. Протокол: `EBALA_0.56_Stage1_Tests.log` (передаётся отдельно от архива исходников).

Новые контрольные тесты — `snow_056_stage1_test.go`, семь тестовых функций. Дополнительно успешно пройдены старые тесты, приведённые к утверждённому отсчёту β.

Тесты выполнялись в Linux, не в Windows. Windows GUI и Microsoft Office не испытывались. **EXE не создавался и не включён в комплект.**
