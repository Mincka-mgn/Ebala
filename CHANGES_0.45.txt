Ebala 0.45 — изменения и результаты проверки
Дата сборки: 2026-11-02

РЕАЛИЗОВАНО
1. Раздел «Снеговая нагрузка» разделён на два переключаемых представления
   «Исходные данные» и «Результаты расчёта» внутри одного окна.
   Вкладка исходных данных содержит ввод геометрии, увеличенный рисунок
   покрытия и отдельный план зон для покрытия с продольным фонарём.
   На вкладке результатов отображаются эпюры, варианты, описания и экспорт.
2. По Б.3 в экран результатов добавлен утверждённый план зон A/B/C.
   Рисунок хранится в SVG и PNG в Resources/SnowRoofs.
   В Word он выводится перед расчётными таблицами.
3. По Б.3 два нормативных варианта в пользовательском представлении
   объединяют зоны A/C/B, действующие одновременно. Зона B у торца
   фонаря имеет коэффициент μ=1,0 в обоих вариантах. В Word каждая зона
   имеет свою числовую таблицу и эпюру под общим вариантом.
4. По Б.2 зеркальные эпюры скрыты из списка на экране и Word; вместо
   второго рисунка дано пояснение о применении схемы зеркально.
   В подробном Excel и расчётных данных зеркальный случай сохранён.
5. Утверждённый SVG шедового покрытия с H и ℓ добавлен в ресурсы.
   В выборе типов покрытий добавлена заглушка «Шедовое покрытие» с
   утверждённым рисунком. Кнопка «Рассчитать» сообщает, что нормативный
   алгоритм по Б.4 ещё не реализован, без выдачи фиктивной нагрузки.
6. Нормативная нумерация пунктов Б.1/Б.2 из имен загружений не навязывается;
   ссылки на СП остаются в основаниях расчёта.
7. Сборка Windows GUI (PE subsystem 2), без привязанной консоли.

ОТЛОЖЕНО / НЕ ВЫПОЛНЕНО
- Полный расчёт шедовых покрытий по Б.4. Сейчас утверждён рисунок,
  расчётная заглушка явно сообщает об отсутствии алгоритма.
- Дополнительная местная повышенная снеговая нагрузка по Б.3 для
  плоских скатов шириной b>24 м. Действующий блокирующий контроль
  сохранён, некорректный расчёт не выполняется.
- Расчёты продольных фонарей, открытых сверху, и зенитных фонарей:
  по согласованию отложены.
- Полная переработка прочих схем приложения Б и ветровая аэродинамика:
  по согласованию отложены.
- Отдельная сборка для Windows 7 SP1 x64: не готова. Использован Go 1.23.2.
- Интерактивное испытание на настоящем компьютере Windows и открытие
  DOCX/XLSX в Microsoft Word/Excel: в этой среде не выполнялись.
- Интерфейс использует высококачественные PNG-версии утверждённых SVG,
  а исходные редактируемые SVG включены в ресурсы.
