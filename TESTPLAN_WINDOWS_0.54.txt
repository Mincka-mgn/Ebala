Ebala 0.54 — обязательная проверка в Microsoft Excel на Windows

1. Распакуйте архив Ebala_0.54.zip целиком и запустите Ebala_0.54.exe.
   Windows x64, GUI без дополнительной консоли.
2. Восстановите/откройте исходный проект объекта, по которому ранее была
   создана дефектная «Общая ведомость нагрузок.xlsx». Сформируйте новую книгу.
   Старую книгу не использовать для инженерных численных выводов.
3. Убедитесь, что Excel открывает документ без «Восстановить содержимое».
4. На листе «Коэффициенты 1» проверьте B2 -> «Исходные данные 1»!B3;
   на листе «Коэффициенты 2» B2 -> «Исходные данные 2»!B3.
5. В каждом из 14 снеговых загружений проверьте формулы коэффициентов,
   таблиц, границ зон и пространственных сеток; ссылки должны иметь
   индекс соответствующего загружения. Гололёдные листы — свой индекс.
6. Измените Sg только в «Исходные данные 1»!B3, пересчитайте (F9),
   проверьте изменение расчётных значений только первого загружения;
   второе должно остаться без изменений. Затем повторите наоборот.
7. Проверьте, что формулы рассчитывают числа, а не #REF!, #VALUE!,
   #DIV/0!, #NAME? и не выводят пустые итоги при заполненных исходных.
8. Проверьте крановые, транспортные, весовые и временные разделы,
   а также формирование общего Word-отчёта, сохранение/повторное открытие проекта.

До выполнения проверки в Microsoft Excel полный выпуск не считать принятым.
