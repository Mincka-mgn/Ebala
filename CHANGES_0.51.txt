Ebala 0.51 — ревизия архитектуры Excel
Дата: 04.11.2026
База: Ebala 0.50, требования PROJECT.md от 04.11.2026.

НАЗНАЧЕНИЕ ВЕРСИИ
Изменён преимущественно экспорт XLSX. Расчётное ядро, нормативные алгоритмы ядра и формирование Word не подвергались самостоятельной ревизии в этом выпуске. Новые формулы Excel требуется отдельно проверить численно при следующем аудите.

РЕАЛИЗОВАНО
1. Для снега добавлены отдельные листы с таблицами 10.2 и 11.2 СП 20.13330.2016. Табличные значения присутствуют в файле, высотная интерполяция k(H) и выбор kv выполняются формулами Excel по исходным данным.
2. Коэффициенты снега ce, ct и основные геометрические параметры вынесены в вычисляемые ячейки. Переписан выбор ветвей формул для основных скатных, сводчатых, многопролётных, круглых схем. Варианты частичного загружения используют условные Excel-формулы по координате, а не готовые коэффициенты μ из Go.
3. Для Б.15а сформированы самостоятельные формульные листы геометрии и пространственных сеток. Убраны клиентские контрольные колонки «μ Go» и «Excel−Go»; сопоставления перенесены в тесты.
4. Для гололёда перенесены в собственные листы таблицы 12.2, 12.3, 12.4 СП; при наличии ветра также таблицы 11.1 и 11.2. Добавлены построчные выборы и интерполяции по высоте и диаметру. Значения k, μ1 и давления в расчётном листе ссылаются на нормативные таблицы.
5. Самостоятельный XLSX собственного веса разделён на «Исходные данные» и «Собственный вес»; толщины, плотности, нормативные готовые нагрузки и γf доступны для редактирования, суммы вычисляются по формулам.
6. В общем XLSX добавлены отдельные исходные и вычислительные листы собственного веса и временных нагрузок; итоговые показатели из них доступны по ссылкам Excel.
7. Для доступного экспорта общей ведомости из главного окна подключён единый генератор сохранённых блоков, вместо старой демонстрационной ветки, где применимо.
8. Восстановлено обязательное пояснение, начинающееся «На этом листе…», в нескольких ранее неохваченных XLSX; логические поля не выдаются за единицы измерения «0/1».
9. Версия и инструкции Windows x64 обновлены до 0.51. Внесены новые тесты XLSX-структуры, таблиц СП и формульных зависимостей. Устаревшие тесты, требовавшие готовые числа Go или фиксированные позиции листов, обновлены под новую архитектуру.

ОСТАЛОСЬ / НЕ ПОДТВЕРЖДЕНО
1. ПОЛНОТА: архитектурный принцип «Excel получает только исходные данные» НЕ доведён до всех старых путей и всех модулей. Часть общего отчёта (особенно крановые схемы, транспорт, местность, часть временных позиций) по-прежнему может использовать готовые численные показатели и исторические формулы. В отдельной проверке допустимы только матричные исключения для расстановок кранов.
2. Для общей ведомости собственного веса исходная модель сохраняет уже принятые нормативные веса слоёв, а не всю геометрию каждого материала; поэтому общий XLSX может независимо пересчитать применение γf, но не восстановить все толщины и плотности. Отдельный XLSX собственного веса содержит исходную геометрию.
3. Проверка формул Excel в настоящем Microsoft Excel и перерасчёт после редактирования исходных данных НЕ проведены. Проверка целостности OOXML не равна численной поверке Excel и СП.
4. Нет независимых табличных эталонов для всех снеговых схем. Некоторые формулы сложных вариантов нуждаются в дополнительном аудите, в частности геометрические ветви, линейные схемы перепадов и частичные загружения. Неполнота формулы не должна маскироваться готовым μ из ядра.
5. Переход на другой интервал при изменении количества точек или размеров расчётной сетки в XLSX не добавляет/удаляет строки динамически: исходный набор строк фиксирован моментом экспорта, а их числовые значения пересчитываются формулами.
6. Диалог подтверждения изменения диаметра сферы с конусом, прочие блокировки, полноценная проверка Word и самостоятельный модуль ветра относятся к следующим задачам, не являются частью 0.51.
7. Windows GUI не запускался на Windows; файлы Word/Excel не проверялись визуально в Microsoft Office.

ПРОВЕРКИ
- Полный прогон: GO111MODULE=off go test -v ./... -count=1 -timeout 110s — PASS (48.086 с). Включает новые тесты XLSX и регрессию остальных модулей.
- Windows x64 GUI: GOOS=windows GOARCH=amd64 GO111MODULE=off go build -trimpath -ldflags="-H=windowsgui -s -w" -o Ebala_0.51.exe .
- Проверка формата PE (GUI subsystem), целостности ZIP и XML выполняется при упаковке.
