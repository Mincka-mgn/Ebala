EBALA 0.35 — исправления интерфейса, эпюр и совместных загружений
1. Климатический справочник: выбранный регион задаёт начальную позицию в полном списке, без блокировки остальных регионов. Поиск выполняется по всей базе.
2. Кнопки доступа к климату: «Температура и ветер по СП».
3. Исправлено расположение переключателя единиц кПа / кгс/м² без перекрытия заголовка.
4. Эпюры Word/Excel: сглаженные высококачественные числовые подписи на основе встроенного графического атласа, без передачи файлов шрифтов. Подписаны отдельные участки равномерной интенсивности (до 10 групп), разнесены подписи по уровням для читаемости.
5. Для двух продольных фонарей добавлены совместные варианты внутри одинаковых продольных зон А/С, в том числе пропущенная пара 1С + 1С с μ2=1,1 при a=b=6 м. Это альтернативные загружения, не суммируются. Для смещённых фонарей требуется проверка взаимного расположения.
6. Регрессионные тесты: одновременный C+C и корректность PNG эпюры.
Ограничения: полная нормативная проверка сочетаний при произвольном смещении фонарей в плане и ранее отмеченные ограничения других модулей остаются.
