ВЫПОЛНЕНО В ЭТАПЕ 1 (сохранено во втором)
- Исправлены тёмные полосы Win32 (конфликт стилей STATIC) и высота списков COMBOBOX.
- Ручное w0 с независимым источником; возврат к району, пояснения типов А/В/С.
- Два фасада L/H/h и B/H/h, один с окном; на экране результатов собственная схема зон.
- Шаг эпюры по умолчанию 2,5 м с обязательными точками 0, 5 и H.
- Исправлен размер поперёк потока в определении z_e по 11.1.5.
- Для здания только два направления: вдоль и поперёк конька.
- Крупная собственная схема со стрелкой ветра, D/E и пунктиром конька.
- Подписи «Разрежение»/«Давление» разнесены по краям и скрываются при отсутствии знака.

ВЫПОЛНЕНО В ЭТАПЕ 2
- Добавлены расчётные зоны двускатной кровли по рисунку В.4, таблицам В.3а и В.3б.
- Ветер поперёк конька: зоны F, G, H, I, J; вдоль конька: F, G, H, I.
- Для промежуточных углов 15°–30° (по таблице В.3а) сохраняются две ПОЛНЫЕ
  альтернативы знаков, не смешиваются экстремальные значения разных ветвей.
- Угол β вычисляется из L и h; аэродинамические коэффициенты линейно
  интерполируются из исходных нормативных JSON. Табличные углы и границы
  знаковых ветвей также читаются из JSON, не задублированы в Go.
- Геометрия зон представлена прямоугольными областями в плане, отображается
  на собственной схеме; выбранная зона и знаковый вариант выделяются.
- Каждая зона имеет самостоятельный расчёт и связь со своим общим вариантом
  направления ветра. Все данные сохраняются в проекте.
- В DOCX добавлены данные кровли, β, L/B/H/h, зоны, таблицы и знаковые ветви.
- В независимый XLSX включены полные табличные листы В.3а/В.3б, выбор c
  формулами по геометрии и ветви, ζ, ν, k, средняя/пульсационная/расчётная
  нагрузки и расчётные ординаты. Формулы зависят от редактируемых источников;
  готовые результаты Go не подставляются вместо расчёта.
- В XLSX все новые ветровые листы начинаются с требуемого пояснения в A1.
- Версия приложения изменена на 0.60; Windows x64 GUI-сборка.

МАТЕМАТИЧЕСКИЕ УСЛОВИЯ И ОГРАНИЧЕНИЯ
- Величины e, e/10, e/4, e/2 и расположение зон соответствуют рис. В.4;
  геометрическое зонирование реализовано в Go согласно рисунку.
- Для кровли расчётное давление назначается по верхней эквивалентной высоте
  H (конёк); отображённая линия не моделирует новое распределение по скату.
- При вычислении пульсационной составляющей расчётная поверхность зоны
  рассматривается в прямоугольной проекции xoy по табл. 11.7. Для сильно
  наклонных и нестандартных форм в программе выдаётся предупреждение о
  необходимости проверить применимость этой модели.
- Экстраполяция c за последние табличные углы не выполняется.
- Резонансные схемы с ручным вводом частот, пиковая ветровая нагрузка,
  вихревое возбуждение и специальные сооружения по-прежнему не реализованы.
- При редактировании геометрии непосредственно в экспортированном XLSX
  пересчитываются числа в существующих листах, но количество листов и состав
  возможных зон/знаковых альтернатив определены в момент экспорта. Для новой
  топологии загружений расчёт нужно повторить в Ebala.
