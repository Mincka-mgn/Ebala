Ebala 0.39 — изменения

1. Модуль гололёда: автоматическая толщина по высоте согласно пункту 12.2 и таблицам 12.1–12.4 СП 20.13330.2016 (изм. № 1–6) для диапазонов 5–100, 100–200 и 200–400 м с проверкой необходимых специальных данных.
2. Для горизонтального подвешенного круглого элемента поправка 0,90 по указанию после таблицы 12.4 применяется автоматически при h >= 200 м. Выбор типа элемента заменяет отдельную галочку.
3. Плотность льда по умолчанию 900 кг/м³. Отдельная подтверждённая плотность и данные b(200), b(300), b(400) допускаются в дополнительных настройках с обязательным указанием источника.
4. Расчёт совместного действия ветра и гололёда: ветровой район из таблицы 11.1; высотный k(z) из таблицы 11.2 для местности А/В/С; подтверждённый аэродинамический коэффициент c по приложению В; увеличенный обледеневший диаметр; γf=1,4 для ветра и γf=1,8 для гололёда.
5. Отдельные случаи по п. 12.3: ветер ведущий без гололёда; гололёд ведущий, сопутствующий ветер с ψ=0,25 (гибкие элементы) или ψ=0,6 (прочие). Вертикальную и горизонтальную нагрузки не складывать как скаляры.
6. Пульсационная составляющая ветра учитывается ТОЛЬКО при вводе подтверждённого отношения wp/wm из отдельного расчёта с указанием источника; без этих данных расчёт ветра ограничен средней составляющей и помечен как неполный.
7. Обновлён интерфейс: поле источника метеоданных, плотность и высотные специальные параметры вынесены на отдельную страницу; ненужные поля скрываются в основном окне. После нажатия «Рассчитать» диаграмма четырёх кривых показывается в окне программы (GDI bitmap).
8. Word: упрощённое инженерное изложение, единая таблица по высоте, определения величин, конкретные нормативные ссылки, эпюра совместного действия. Убраны подробные числовые подстановки и отдельная таблица высотных коэффициентов.
9. Excel: исходные данные, формульный расчёт по высоте, общая ведомость и эпюра; новая ветровая часть связана формулами с исходными ячейками.
10. Остальные расчётные модули и нормативные базы унаследованы от 0.38 без изменений расчётных алгоритмов.

Ограничения и особые условия применения

А. При отсутствии независимого расчёта пульсаций нельзя считать ветровую нагрузку полной по п. 11.1.2. Ввод отношения wp/wm предполагает, что оно обосновано для всех выбранных отметок; динамика, резонансное вихревое возбуждение, особые воздействия и сочетания вне п.12.3 не рассчитываются автоматически.
Б. Аэродинамический коэффициент для исходного и обледеневшего сечений задаётся пользователем по применимым схемам приложения В; программа не выполняет автоматический подбор c по числу Рейнольдса, геометрии решётки или данным аэродинамической трубы.
В. Ветровой коэффициент k(z) выше 300 м по п.11.1.6 требует специального обоснования; совместный расчёт с ветром для z>300 м блокируется. Гололёд без ветра допускается рассчитывать до 400 м по выбранной методике.
Г. В районах I, V, горных, северных и особых территориях для некоторых высот требуются наблюдения и соответствующие карты; без подтверждённых данных вычисление блокируется в предусмотренных кодом случаях. Принадлежность к особой географической территории не определяется автоматически только по наименованию населённого пункта.
Д. Для элементов, не являющихся круглыми, ветровая нагрузка выражается давлением Па; переход от давления к погонной нагрузке по ширине проекции требует отдельно обоснованной расчётной схемы.
Е. Проводится расчёт нагрузки, а не проверка напряжений, усилий, устойчивости, выносливости и целостности конструкций.
Ж. Полный набор тестов Go прошёл; EXE собран для Windows amd64, но реальная работа интерфейса на компьютере Windows не проверялась. Word визуально проверен после конвертации в PDF, XLSX проверен на структурную корректность и импортирован с помощью artifact_tool. Прямой пересчёт именно в Microsoft Excel не выполнен.
