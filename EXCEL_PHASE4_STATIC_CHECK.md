# Ebala — этап 4: протокол проверок исходников

**Вид работ:** контрольная точка разработки без компиляции Go, без исполнения Go-тестов и без сборки Windows EXE.

## Фактически выполнено

| Проверка | Результат | Ограничение |
|---|---|---|
| Сверка `PROJECT.md` с этапом 3 | Побайтно совпадает | Архитектурные правила не изменялись |
| `gofmt -l` изменённых Go-файлов | Замечаний не обнаружено | Не является компиляцией или тестированием функций |
| `reference_cases.py` | 10 независимых числовых эталонов успешно рассчитаны | Не выполняет формулы в сгенерированных XLSX |
| `static_checks.py` | 16 проверок статических связей прошли | Не подтверждает правильность OOXML нового экспорта |
| Крановые расстановки | Добавлены общие четырёхлистовые расчёты и XML-регрессии | Написанные Go-тесты **не запускались** |
| Фактическая генерация и пересчёт XLSX из изменённых исходников | **Не проводились** | Обязательны перед итоговым выпуском |
| Microsoft Excel / Windows GUI | **Не проверялись** | Проверяется на финальном этапе |

Дополнительно исправлена граничная геометрия Б.15а: при линейном сопряжении конечный радиус сферы отсутствует, но высоты и угол касательной вычисляются по прямой. Отказ Excel с `1/0` заменён явной вычисляемой ветвью. Добавлены два независимых контрольных случая (α₂ = 18° и 40°), ещё не прогнанные через реальный Excel.

## Открытые критерии

- Независимые эталонные значения для каждой снеговой схемы, всех зон Б.15а, фонарей и перепадов.
- Перерасчёт промежуточных и конечных величин при редактировании входных ячеек с реальным движком формул Excel.
- Удаление старых путей экспорта и проверка всех формульных ответвлений без `NA()` и скрытых заглушек.
- Проверка численных расхождений между Go и Excel по всем поддерживаемым схемам.
- Проверка валидности и читаемости созданных из текущего кода DOCX/XLSX.

**Вердикт:** оснований объявлять все 41 критерия выполненными или выпускать Windows-версию пока нет.
