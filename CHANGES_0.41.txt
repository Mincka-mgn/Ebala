Ebala 0.41 — изменения, проверка и ограничения

ИСПРАВЛЕНО
1. Восстановление Excel после повреждения /xl/worksheets/snow2.xml: строки формульного листа теперь записываются по возрастанию номеров; дубликаты строк и посторонний XML вызывают ошибку генерации вместо выпуска повреждённой книги.
2. Убран обязательный ввод источника для вручную заданного допустимого коэффициента μ₂; диапазон значения по-прежнему проверяется.
3. Гололёд: видимое редактируемое поле Cx и кнопка сброса к автоматически предложенному значению; для проводов и тросов нормативное Cx = 1,2 по п. В.1.12 СП 20.13330.2016.
4. Основное окно гололёда: убраны служебные примечания о механике программы и напоминание о плотности, изменено размещение элементов. В специальных условиях изменены порядок и подписи полей, источник специальных данных указан как материал для включения обоснования в отчёт.
5. Word: значения нагрузок подписаны полными наименованиями, принятые обозначения описаны отдельными строками, ссылки приведены к виду «п. ... СП 20.13330.2016». Убраны не относящиеся к результатам технические предупреждения. Формат — A4, книжный, поля 1,27 см.
6. Разметка графика: автоматически выбираются удобные округлённые шаги осей вместо дробных делений.
7. Сохранение документов: новый номер (1), (2) и т. д. при совпадении имени; после сохранения предлагается сразу открыть созданный Word/Excel в приложении по умолчанию.
8. Экран «Состав общего отчёта»: сгруппированы сохранённые расчётные блоки, поддерживаются перемещение ↑/↓, исключение ×, двойной щелчок с переходом в модуль. Несколько снеговых и гололёдных схем сохраняются в проекте независимо и выводятся в общий Word и Excel.
9. На странице «Местность» предупреждение точно: «ВНИМАНИЕ! База неточна! Проверять по картам обязательно!».
10. В модуле расстановки мостовых кранов кнопка названа «Сохранить схемы картинками».
11. Главная страница и раздел «О программе»: отображается версия 0.41, убрана нижняя повторяющаяся надпись, ссылки в разделе «О программе» можно выделять и копировать.
12. Переход из общего отчёта к строкам собственного веса и временных нагрузок выбирает соответствующую запись для просмотра и редактирования.

ПРОВЕРКА
- go test ./... (GO111MODULE=off) — успешно.
- Сборка для Windows amd64 в оконном режиме — успешно.
- Автоматические тесты на порядок строк Excel, дубликаты, сохранение нескольких блоков, их перемещение и удаление, экспорт двух снеговых и двух гололёдных схем — успешно.
- Контрольная общая книга: XML корректен, 37 листов, 364 формулы, две настоящие диаграммы; машинная проверка структуры и чтение книги проходят.
- Контрольный Word-отчёт с несколькими схемами визуально проверен после рендеринга.

ОГРАНИЧЕНИЯ ПРОВЕРКИ И ПРИМЕНЕНИЯ
- Запуск Windows GUI и проверка масштабирования окон на конкретном компьютере пользователя не выполнялись.
- Непосредственный запуск и открытие контрольной книги в Microsoft Excel не выполнялись. Устранена доказанная причина восстановления snow2.xml, однако проверка с установленным Microsoft Excel необходима; проблемы в других расчётных книгах не исключены.
- Для собственного веса состав отчёта оперирует отдельными строками существующего расчёта; независимые экземпляры полной многослойной конструкции пока не реализованы. Для временных нагрузок редактируется строка существующей ведомости.
- Расчёт пульсационной составляющей ветра без дополнительных исходных динамических характеристик не автоматизирован.
- Для специальных гололёдных территорий и высотных значений требуется фактическое обоснование по нормативной методике; оно не заменяется автоматически вымышленными исходными данными.
- Для конструкций, отличных от проводов/тросов, автоматически предложенное Cx = 1,2 не является универсальным нормативным значением; допускается ручной ввод инженерно обоснованного значения.
