# Ветровая нагрузка Ebala 0.57

Версия 0.57 — первый **реально вычисляющий**, но **не полный по охвату схем**, этап самостоятельного модуля ветра. Программа автономна на Windows x64 и не требует установки Go.

## Как пользоваться

1. В главном меню откройте «Ветровая нагрузка».
2. Выберите ветровой район или укажите своё `w0`; тип местности, высоту сооружения `h`, его размер вдоль ветра `d` (для зданий) и отметку расчёта `z`.
3. Для схем В.1 или В.2 задайте зону аэродинамического коэффициента; если требуемой схемы нет, используйте явное ручное значение `c` и самостоятельно проверьте источник.
4. Укажите способ нахождения `k`: таблица 11.2 или формула 11.4.
5. Для расчёта без резонанса задайте размеры `ρ` и `χ` для ν из таблицы 11.6. Для динамической ветви дополнительно задайте частоту `f₁` и декремент `δ`. Режим «Только средняя» пульсаций не рассчитывает.
6. Нажмите «Рассчитать». Расчёт автоматически сохраняется отдельным блоком общей ведомости. Для следующего варианта используйте «Сохранить и новый»; результаты можно открыть на редактирование из ведомости.
7. «Отчёт DOCX» создаёт текстовый расчёт; «Расчёт XLSX» создаёт независимую электронную книгу с формулами и нормативными данными. Общие отчёты берут только выбранные блоки ведомости.

Единицы ввода приведены возле полей. Знак давления определяется знаком аэродинамического коэффициента. `w₀` вводится в кПа; результаты расчёта в Па внутренне и кПа в интерфейсе.

## Источники и контроль версий

- `WindData/formulas.json` — утверждённые машиночитаемые формулы.
- `WindData/tables_section11.json` — нормативные таблицы раздела 11.
- `WindData/SP20_wind_all_in_one.json` — схемы и коэффициенты приложения В.
- `WindData/MANIFEST_SHA256.json` — контроль целостности данных.
- `Mathematics/Wind_v1_1/` — полный исходный математический архив с документацией и контрольными примерами; поставляется **только с исходниками**.

При расчёте сохраняются снимок входных данных, числовые результаты, формулы, нормативные ссылки, версия данных и их SHA-256. Если JSON повреждён, расчёт остановится с сообщением. Редактирование справочника потребует актуализации контрольного манифеста и повторной проверки контрольных примеров.

## Ограничения и правила расчёта

См. `CHANGES_0.57.txt` и `Mathematics/Wind_v1_1/calculations/docs/LIMITS_AND_AUDIT.md`. **Не принимайте наличие схемы или формулы в JSON за её поддержку интерфейсом.** Полные расчёты по приложению М, специальные сооружения, пиковые нагрузки и вихревое возбуждение НЕ реализованы. Контрольный пример и модульные тесты не заменяют инженерной проверки каждого конкретного случая.

## Для разработчика

Сохраняется однопакетная архитектура Go и Win32 без go.mod. Тестирование в корне исходников: `GO111MODULE=off go test -count=1 ./...`; сборка Windows x64: `GOOS=windows GOARCH=amd64 GO111MODULE=off go build -ldflags="-H=windowsgui -s -w" -o Ebala_0.57.exe .`. Рядом с EXE должны находиться папки `Catalog`, `Databases`, `Maps`, `Resources`, `WindData`.
