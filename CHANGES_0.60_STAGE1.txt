Ebala 0.60 — этап 1 исходников, НЕ РЕЛИЗ, 06.11.2026

Основа: исходники Ebala 0.59 + PROJECT.md + Ebala_Wind_Mathematics_v1_1.
Статус: этап замечаний выполнен НЕ ПОЛНОСТЬЮ. По указанию пользователя готовый Windows EXE не создаётся и не поставляется.

СДЕЛАНО
1. Исправлена причина тёмных прямоугольных полос Win32: для STATIC-элементов удалён флаг ES_MULTILINE, который в STATIC означал стиль SS_BLACKRECT.
2. Исправлена причина нераскрывающихся COMBOBOX: MoveWindow больше не обрезает их выпадающую часть до 28/29 пикселей; сохраняется высота 265 пикселей списка.
3. w0 можно редактировать напрямую. Изменение пользователем переводит поле в режим независимого ручного исходного давления; выбор района скрывается, доступна кнопка возврата к районному значению. Сохраняется ранее выбранный район.
4. Добавлена кнопка пояснения типов местности A/B/C, текст основан на п. 11.1.6 СП 20.13330.2016.
5. Два отдельных SVG/PNG-фасада: торцевой L/H/h с окном и продольный B/H/h. В исходных данных вместо составной нормативной иллюстрации для здания показываются эти изображения, с согласованными буквами.
6. Шаг эпюры по умолчанию 2,5 м, вместо текста «Авто». Сохраняется пользовательский шаг, обязательные отметки 0, 5 (при H>=5), верхняя отметка.
7. КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: в формулу эквивалентной высоты пункта 11.1.5 для здания теперь передаётся поперечный к ветру размер, а не длина вдоль потока. На этом же основании поправлены пояснения DOCX/XLSX.
8. Для здания оставлены два расчётных направления: вдоль конька и поперёк конька. Убраны дубликаты противоположных направлений.
9. На экране результатов удалены нормативные PNG; создана увеличенная авторская схема зон стен, с D/E, стрелкой ветра, пунктиром конька и выделением выбранной зоны. Положение зон зависит от выбора направления.
10. Подписи давления под линией графика разнесены по левому/правому краям и помещены над числовой осью. Подписи скрываются, если соответствующего знака нагрузок в данных нет.
11. Актуализированы имеющиеся тесты ориентаций, добавлены регрессии для шага, двух направлений, нормативного поперечного размера и ручного w0.

НЕ СДЕЛАНО, ТРЕБУЕТ ЭТАПА 2
A. Полный ветровой расчёт двускатной крыши по таблицам В.3а/В.3б СП 20.13330.2016, включая все зоны покрытия, условия применимости и альтернативные знаковые варианты для В.3а при промежуточных углах.
Б. Показ зон двускатной кровли на общей авторской схеме результатов. Сейчас схема показывает только зоны стен.
В. Интеграция зон покрытия с группами загружений, сохранением, DOCX и независимым формульным XLSX; контрольные примеры кровельных схем.
Г. Контроль Win32-интерфейса на реальной Windows в разных масштабах и проверка пересчёта XLSX именно в Microsoft Office.

ПРИНЦИПИАЛЬНОЕ МАТЕМАТИЧЕСКОЕ ЗАМЕЧАНИЕ
П. 11.1.5 СП 20.13330.2016 для зданий предписывает кусочное определение z_e через поперечный размер d и высоту H. Оно допускает постоянные участки и скачки на границе H-d; поэтому требование «после 5 м эпюра обязательно плавно растёт» не следует из указанной нормативной ветви для всех геометрий. Алгоритм по утверждённой спецификации не заменялся произвольным сглаживанием. Для отдельных башенных сооружений другой алгоритм z_e=z.
