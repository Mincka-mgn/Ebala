# Статус, ограничения и оставшаяся поверка

**Проверено**: численные коэффициенты и уравнения раздела 11 по изображениям загруженного СП; перечень аэродинамических разделов В.1.1–В.1.17, формулы В.1–В.12, приложение М. Таблицы раздела 11 вручную перенесены, но независимая посрочная двойная проверка не проводилась. Структурные тесты и отдельные численные примеры проходят.

**Не утверждать как готовое к автоматическому вычислению без следующих действий**:

- В.5 и В.6: конфигурации альтернатив и определение геометрии по чертежу требуют контрольных расчётов.
- Рис. 11.1 (ξ): в расчётной базе принята отдельно согласованная инженерная аналитическая аппроксимация (`11.1.xi_davenport_approx`), не нормативная формула СП. Предварительно оцифрованные точки остались только для контроля (max |Δξ|<0,10, max относительная ~6%). Не считать картинку нормативной цифровой таблицей; не заявлять 3% абсолютной точности по всему полю. Для δ между 0,15 и 0,30 вычислять ξ непосредственно по формуле, без интерполяции между кривыми. Для значений вне проверенной области выводить предупреждение.
- В.16 и В.17: математические приближения графиков, не собственные формулы СП. Ограничение В.16 строго `Δ/d<10^-4`, ошибка v0.4 исправлена в отдельном справочнике v0.5.
- П. 11.1.11, таблица 11.6: билинейная интерполяция записана как вычислительное предложение, не обязательное дословное требование пункта.
- В.1.9: при `5%<μ<30%` применять только осознанно принятые пользователем данные/режим, не интерполировать по умолчанию.
- В.1.5: буквенное определение относительного λ и геометрию фонарей перепроверить непосредственно по рисункам перед кодом.
- М.1–М.21: для M.4, M.7–M.12, M.18–M.21 нужны пространственная модель, собственные формы, интегрирование и независимая проверка. `formulas.json` хранит математическую *спецификацию*, не реализованный алгоритм.
- Испытания зданий повышенной ответственности, неблагоприятное обтекание городских комплексов, сложные наклонные и близкорасположенные объекты выходят за универсальные табличные схемы.
- Сейсмика, гололёд и климатические карты — самостоятельные справочники; в базу включены только правила сочетания ветра и гололёда из 12.3.

Принятые ограничения должны показываться инженеру **в интерфейсе**, но не переноситься в чистовой DOCX/XLSX.
