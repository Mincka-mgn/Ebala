# Решение по замене рисунка 11.1 аналитической формулой (06.11.2026)

## 1. Цель

В расчётной базе Ebala для динамического коэффициента ξ не хранить набор произвольно оцифрованных и интерполируемых кривых рисунка 11.1 СП 20.13330.2016 (изменения № 1–6), а использовать непрерывную инженерную аппроксимацию, основанную на спектральном подходе Давенпорта. Она позволяет вводить действительный суммарный логарифмический декремент δ напрямую.

## 2. Принятая модель

`xi = sqrt(1 + pi**2/(3*delta_damp) * Tg1**(2/3) / (1 + Tg1**2)**(4/3))`

где `Tg1` — безразмерный период по формуле (11.8); `delta_damp` — суммарный логарифмический декремент по 11.1.8. Формула возвращает ξ для использования в нормативной формуле (11.7), но **не опубликована как формула СП**. Это модельная реконструкция графика, а не утверждение о точном авторском способе его построения.

## 3. Инженерное обоснование допустимости

- Нормативный рисунок 11.1 содержит только три толстые кривые для δ=0,15, 0,22 и 0,30. Печатная точность графика принципиально ограничивает достоверность считывания ординат вручную.
- Проведено сравнение с 24 ранее ориентировочно оцифрованными контрольными значениями для `Tg1` от 0 до 0,30 и трёх указанных δ.
- Максимальное абсолютное расхождение `|xi_formula - xi_рисунок|` = **0.0953**, среднеквадратичное = **0.0577**; максимальное относительное (к считанному ξ) = **5.98%**.
- Характерный пример: отклонение 3,0 против 3,1 составляет ~3,3%. Такие различия сопоставимы с точностью графического считывания; пользователем принято упрощение в целях отказа от оцифровки.
- **Не утверждать**, что максимальная относительная ошибка не превышает 3%: на части опорных точек (в особенности на малых Tg1) она больше, до ~6%. Также критерий 0,10 — практический порог сравнения с приблизительно снятым рисунком, а не строгая погрешность относительно неизвестной авторской функции.

## 4. Интерполяция и ограничения

- **Для ξ интерполяция по декременту не требуется.** При `0,15 < δ < 0,30` подставлять фактическое δ в формулу; значение непрерывно зависит от δ. Промежуточные δ проверены на математическую корректность/монотонность, но **не представлены отдельными нормативными кривыми**.
- Проверенный по печатному рисунку диапазон: `0 <= Tg1 <= 0.30`, опорные декременты `δ∈{0.15, 0.22, 0.30}`. Математически: `Tg1>=0`, `δ>0`.
- Выход за печатный диапазон: предупреждать пользователя о неподтверждённой точности и показывать исходное значение. Не экстраполировать скрыто или обрезать параметры до ближайшей границы. Математически определённый расчёт не блокировать только из-за выхода за диапазон.
- `delta_damp` — сумма конструкционного и аэродинамического декрементов; при специальных демпфирующих устройствах учитывать условия 11.1.8.
- **Не переносить это решение на таблицу 11.5:** предельный период `Tg_lim` задан там только для δ=0,15, 0,22, 0,30. Способ выбора/интерполяции для другого δ следует определить и документировать отдельно.
- При нескольких значимых собственных формах колебаний действуют требования раздела 11 и приложения М. Наша одноформовая аппроксимация не заменяет их.

## 6. Дополнительная историческая проверка (ЦНИИСК 1978)

В приложении 2 старого Руководства ЦНИИСК (1978), формула (48), опубликован интеграл для динамического коэффициента. Его численная интеграция сопоставлялась с таблицей 6 того Руководства (например, при ε=0.25 и δ=0.15: около 2.928 против 2.93); это подтверждает метод старого документа.

Современный рисунок 11.1 СП20 имеет другую историю нормализации и не объявляется дословной формулой (48). В предыдущем сравнении с предварительной оцифровкой современного рисунка историческая интегральная модель дала макс. абсолютное расхождение около 0.113, а принятая простая формула — 0.095. При такой практической точности оставляем простую формулу, без добавления численного интегратора.
