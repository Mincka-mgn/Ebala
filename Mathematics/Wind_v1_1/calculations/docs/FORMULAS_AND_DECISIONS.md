# Общее правило вычисления ветра

Нормативная основная: `w = w_m + w_g`; `w_m = w0*k(z_e)*c`, `w_g` в упрощённом случае `w_m*ζ(z_e)*ν`; в динамическом одноформовом `w_m*ξ*ζ*ν`. Нагрузки внешнего давления, внутреннего давления и трения являются разными компонентами с отдельными направлениями; положительное/отрицательное давление сохраняется по знаку.

## Последовательность

1. Расчётное направление ветра → район/`w0`, тип местности A/B/C (с ручной корректировкой).
2. Геометрия здания/элемента → `z_e` по п. 11.1.5 (три режима `h<=d`, `d<h<=2d`, `h>2d`). Для труб и мачт `z_e=z`.
3. `k(z_e)` по таблице 11.2 либо формуле 11.4; `ζ(z_e)` по 11.4 либо формуле 11.6. Не смешивать источники без отметки.
4. Выбор аэродинамической схемы и нормативного `c` по справочнику, в том числе альтернативные направления/ветви.
5. `w_m`; проверка `f_1` относительно `f_lim`: если `f_1>f_lim`, форма 11.5; если `f_1<f_lim<f_2`, форма 11.7 и график динамичности 11.1; при нескольких формах требуется приложение М.
6. Коэффициент корреляции `ν` по размеру расчётной поверхности и табл. 11.6–11.7.
7. Основная нагрузка и независимые варианты загружения; расчётное значение с `γ_f=1,4` (для вихревого возбуждения 1,0).
8. Отдельно пиковые действия по 11.10 и В.1.17, отдельно проверка вихревого резонанса, при необходимости М.

## Важно по схемам

- В.1.2, В.1.3, В.1.9, В.1.17 могут создавать **альтернативные, а не суммируемые загружения**.
- В.16: только `Δ/d<10^-4` по СП (в v0.4 была ошибка `<5·10^-4`, исправлена в v0.5). Тригонометрическая формула c_beta — **не формула СП**, а согласованная аппроксимация (болгарский инженерный приём).
- В.17: непрерывная аппроксимация по фактической шероховатости и альтернативный дискретно-консервативный выбор; оба режима инженерные, источник СП по-прежнему график.
- Интервал проницаемости `5%<μ<30%` не имеет явной формулы в В.1.9; скрытую интерполяцию не вводить.
- Не подменять динамику на трёх формах коэффициентом ξ для одной формы.
- Нет единой «площади ветра»: для `ν`, `c_e`, `c_x` площадь и размер могут определяться по-разному.

## Исправленные формулы приложения М (v0.2)

- М.11: `Delta2_k = (1-(f_spectral/f_k)**2)**2 + gamma_k*(f_spectral/f_k)**2` (γ_k без возведения в квадрат).
- М.18: `xi_s_squared <= (1+epsilon_D)*v0_squared`. Аргумент `v0_squared` определяется по интегралу М.20, в отличие от `V0` по М.14 и М.16.

## Рисунок 11.1 и коэффициент ξ (решение 06.11.2026)

Для одноформового расчёта (11.7) ξ вычисляется формулой `11.1.xi_davenport_approx` через `Tg1` и суммарный `delta_damp`, без промежуточной интерполяции по трём нормативным кривым. Это принятая инженером аппроксимация рисунка, **не формула самого СП**. Погрешность согласована по масштабу бумажного рисунка, а не как строгая гарантия ≤3% по всей области. Приложение М и таблица 11.5 по-прежнему требуют собственной методики. Подробнее в `docs/FIGURE_11_1_APPROXIMATION_DECISION.md`.


## Уточнение обозначений и единиц (v0.4, 06.11.2026)

- `f_rise` — стрела подъёма свода или купола, м (на рисунках В.5–В.6 обозначена `f`).
- `f_spectral` — текущая частота для спектральных функций и интегрирования приложения М, Гц (в формулах М обозначена `f`).
- `f_k` — собственная частота k-й формы, Гц; не путать с аргументом интеграла `f_spectral`.
- `v0_squared` — **безразмерная** величина по (М.20), unit `1`, потому что `S_v0` имеет размерность с, `r_m` безразмерна, а `d(f_spectral)` — Гц.
- `V0` — физическая скорость ветра, м/с. Квадрат `V0` имеет м²/с² и не подставляется в (М.18).
Нормативные символы не изменены, изменены лишь уникальные идентификаторы для расчётного ядра.
