# Исправление области применения В.16

По оригинальному п. В.1.12 СП 20.13330.2016 (редакция с изменениями № 1–6) график распределения c_β по окружности цилиндра приведён **при Δ/d < 10^-4**.

В версии v0.4 ошибка: записано `<5·10^-4`. Исправлено во всех машиночитаемых файлах и инструкциях v0.5. Никакие числовые табличные данные и графические аппроксимации не изменялись. Новое ограничение — информация для инженера; математически вычислимый результат не должен блокироваться безусловно, согласно PROJECT.md.
