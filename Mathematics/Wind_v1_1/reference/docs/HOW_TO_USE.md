# Как пользоваться справочником в расчёте

**Цель:** определить коэффициенты по таблицам и семи рисункам приложения В СП 20.13330.2016, не загромождая программный код нормативными числами. Это справочник коэффициентов, **не полный алгоритм расчёта ветра** по разделу 11.

## 1. Порядок для любого коэффициента

1. Пользователь выбирает тип сооружения, его геометрическую схему и направление ветра. Для таблиц со схемами посмотрите `figures/` или сам СП.
2. Введите геометрию и требуемые аргументы: `f/l`, `h1/l`, `h1/d`, `Re`, `Δ/d`, `l/d`, `λ_e`, `φ` и т.д. Каждый аргумент безразмерен, если не указано иное. `Δ` в таблице В.11 задаётся в метрах; `Δ/d` образуется делением на диаметр в тех же единицах.
3. Выберите **таблицу / рисунок / группу кривых**. Табличное значение читается по полному ключу (таблица, схема, вариант, входные параметры). Не выбирать лишь по совпадению коэффициента.
4. Для прямолинейных графиков рассчитайте значение между соседними точками выбранной кривой по `linear` или `log10_x` из `data/straight_graphs.json`. Для `log10_x` аргумент строго положителен.
5. Если на рисунке несколько *семейств кривых*, сначала выберите семейство по `data/branch_selection_rules.json`. **В.14 и В.16** используют дискретный выбор кривой. **В.17** использует непрерывную аналитическую зависимость по Δ/d по умолчанию; альтернативно допускается консервативный дискретный выбор.
6. Когда получено `c_x∞`, рассчитайте `λ=l/b`, назначьте `λ_e` по В.10, определите `k_λ` по В.23 и получите `c_x=k_λ*c_x∞` там, где это требуется СП. Отдельные значения внутреннего давления и зон не суммируйте без оснований в применяемом нормативном случае.
7. Храните в результате: идентификатор источника (таблица/рисунок), выбранную ветвь, её исходные точки/параметры, исходные числа, способ расчёта и полученный коэффициент.

## 2. Пять графиков с прямолинейными участками

- **В.5, сводчатая кровля.** Найдите `x=f/l`, выберите группу `c_e1` либо `c_e2`, параметр `h1/l`. При `h1/l>=0.5` и `0.2<=f/l<=0.3` **считайте обе альтернативы** `c_e1`, не усредняйте и не смешивайте их в одну эпюру.
- **В.6а, купол.** Найдите `f/l` и высотный параметр `h1/l`, определите отдельно A, B, C; между промежуточными поперечными сечениями допускается линейная интерполяция коэффициентов. Способ для промежуточных `h1/l` не объявлять автоматически нормативным без отдельного решения.
- **В.14, сфера.** Задайте `Re` и `Δ/d`. По шероховатости возьмите дискретную опорную кривую (в спорном случае большее сопротивление), внутри неё вычислите `c_x(Re)` по логарифмической оси. Отдельно соблюдайте условия В.1.11, включая поправку на положение сферы в пространстве.
- **В.19, призматическое сооружение.** Вычислите `l/d`, получите `c_x∞` кусочно-линейно по `log10(l/d)`, затем при необходимости примените `k_λ`.
- **В.23, относительное удлинение.** По схеме В.10 определите `λ_e`, вычислите `φ=ΣA_i/A_k` и выберите опорную кривую. По `log10(λ_e)` получите `k_λ`; если `λ_e=∞`, смотрите предельный случай на рисунке и выбранную нормативную интерпретацию, не вычисляйте `log(∞)` как обычную интерполяцию.

### Пример В.5: две альтернативы

`f/l=0.25`, `h1/l >= 0.5`: из `B5_CE1_HGE05_NEG` получается `c_e1=-0.75`, а из `B5_CE1_HGE05_POS` — приблизительно `c_e1=+0.1333`. Это **два самостоятельных варианта** загружения.

### Пример В.23

Для ветви `φ=1.0`, `λ_e=10`: по оцифрованной кривой `k_λ=0.70`. Это значение для данного справочного графика, не новое табличное значение СП.

## 3. В.16: распределение давления вокруг цилиндра

Дано: `Re`, `δ=Δ/d<10^-4`, угол `β` от 0° до 180°. По `Re` выбирается **одна** из трёх опорных кривых таблицы В.5. Реперные числа `5·10^5`, `2·10^6`, `10^7`; переходы при ориентировочно `1·10^6` и `4.472·10^6` соответствуют ближайшей кривой по `log10(Re)` (наше правило выбора, **не формула СП**).

По выбранной строке возьмите `β_m`, `c_m`, `β_b`, `c_b` и вычислите `c_p(β)` по трем кусочным формулам в `docs/MATH_AND_STATUS.md` (или `formulas/curved_graphs.json`). Это **болгарская кусочная тригонометрическая аппроксимация**, опубликованная в инженерном примере по БДС EN 1991-1-4 и привязанная к нормативным точкам В.5; не формула самого СП. Принятой ранее степени 4 здесь больше нет.

**Важно о знаках:** для разрежения неблагоприятнее *более отрицательное* `c_p`, для положительного давления — *более положительное*. Если выбор соседней кривой спорный, рассмотреть обе полные распределённые эпюры как альтернативные варианты; не собирать одну искусственную эпюру из переключений по каждой точке окружности.

Пример: при `Re=2·10^6`, `β=100°`, `β_m=80°`, `β_b=120°`, `c_m=-1.9`, `c_b=-0.7`:
`c_p=-0.7-(-0.7+1.9)*cos(π*(100-80)/(2*(120-80)))≈-1.54853`.

Внешний коэффициент с учётом относительного удлинения определяется отдельно по тексту В.1.12: для отрицательных ординат требуется `k_λ`, для положительных он принимается равным 1.

## 4. В.17: лобовое сопротивление цилиндра

Входы: рассчитанное по СП число `Re` и фактическая относительная шероховатость `δ=Δ/d`, где `Δ` из В.11 или задана пользователем.

**Основной режим `CONTINUOUS_LOG_ROUGHNESS`:**

1. Если `δ>=0.05`, взять плато `c_x∞=1.2`.
2. Если `0<=δ<=1e-5`, взять `δ_eff=1e-5` (крайняя кривая, включая идеально гладкую поверхность); в остальных случаях до `0.05` использовать `δ_eff=δ`.
3. Вычислить `c_rough=1.2+0.18*log10(10δ_eff)/(1+0.4log10(Re/10^6))`, `c_down=0.11/(1.6Re/10^6)^1.4`, `c_x∞=max(0.4,min(1.2,c_down),c_rough)`.
4. Если предусмотрено СП, отдельно учесть `c_x=k_λ*c_x∞` по В.10 и В.23. Для проводов и тросов действуют особые нормативные указания, которые эта формула не заменяет.

**Альтернативный режим `DISCRETE_CONSERVATIVE_UPPER_COEFFICIENT`:** находим две опорные кривые, между которыми находится фактическое `δ`, рассчитываем коэффициент на каждой при **одном и том же Re**, принимаем большее значение. Для верхней опорной серии `δ=0.05` используем `1.2`. Это не интерполяция. Входное значение `δ` сохраняем как введено.

**Контрольный пример:** при `Re=10^6`, `δ=3·10^-4`: непрерывный режим `c_x∞≈0.74588`; дискретный консервативный `c_x∞=0.84` (верхняя опорная серия `10^-3`). На самих опорных точках два режима совпадают.

**Оговорки:** формула В.17 является инженерной реализацией с европейской аналитической ветвью и нашей визуальной поправкой `1.6` в нисходящей ветви. Ни сама составная формула, ни подстановка любой промежуточной шероховатости прямо не установлены текстом СП. У порога `δ=0.05` нормативное плато может дать небольшой скачок, его не сглаживаем самовольно. Подробности и псевдокод — `docs/V17_MODES.md`.

## 5. Выходы за область действия

- Не заменять отсутствие исходных сведений числом 0. Для идеально гладкой поверхности `δ=0` на В.17 выбирают опорную кривую `δ≤10^-5` с `δ_ref=10^-5` для формулы; нельзя вычислять `log10(0)`.
- Не прятать выход за границы графика и не выдавать дальнейшее продолжение линии за нормативное значение.
- Согласно `PROJECT.md`, пользователь может вручную выбрать ветвь и выполнить математически допустимое вычисление с **предупреждением в интерфейсе**. Не выполнять математически неопределённые операции (`log10(0)`, деление на ноль и т.п.).
- Не переносить служебные предупреждения в выдаваемый Word/Excel; выводить точные нормативные ссылки и реально использованные формулы. Для Excel предусмотреть независимое вычисление по данным, а не готовые результаты ядра.
