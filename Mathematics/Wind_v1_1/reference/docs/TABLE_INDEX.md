# Состав нормативных таблиц и требуемый выбор схемы

Используются исходные номера таблиц СП 20.13330.2016, приложение В (с изменениями №1–6). Числовые значения в `data/tables_appendix_v.csv`, колонки `table_id`, `scheme_id`, `variant`, `input_1_*`, `input_2_*`, `result_*`, `condition`, `source_note`. Разделитель CSV — **запятая**, десятичный — **точка**, кодировка **UTF-8**. Поле пустое не равно числу ноль.

| Таблица | Что содержит | На что смотреть при выборе |
| --- | --- | --- |
| В.1 | Зоны A–D плоских сплошных конструкций | Привязка зон к рисунку В.1 |
| В.2 | Зоны A–E стен прямоугольного здания | Геометрия e=min(b,2h), рисунок В.3 |
| В.3а | Двускатная кровля, ветер поперёк конька | Угол β, зоны F–J и два варианта знаков для отдельных углов |
| В.3б | Двускатная кровля, ветер вдоль конька | Угол β, зоны F–I |
| В.4 | 4 схемы навесов | Выбор I–IV по эскизам; для горизонтального навеса оба III/IV при α=10° (`figures/Table_V04_canopies.png`) |
| В.5 | Параметры распределения давления вокруг цилиндра | Реперное число Re; угол β_min, c_min, β_b, c_b; рисунок В.16 |
| В.6 | Круглое цилиндрическое сооружение/покрытие | Отношение h1/d; коэффициенты c_e2 и c_i |
| В.7 | Правильные многоугольные поперечные сечения | Число сторон n, направление обдувания |
| В.8 | Экранирование параллельных решётчатых ферм | Заполнение φ, расстояние b/h; отдельно исключение Re≥4·10^5 для трубчатых ферм |
| В.9 | Пространственные решётчатые башни | 3 формы сечения и направления ветра (`figures/Table_V09_schemes.png`) |
| В.10 | Относительное удлинение λ_e | 4 схемы закрепления: λ/2, λ, 2λ, ∞ (`figures/Table_V10_schemes.png`) |
| В.11 | Шероховатость поверхности | Δ в **метрах**; не путать с отношением Δ/d |
| В.12 | Пиковые отрицательные коэффициенты | Зоны A–E стены/покрытия (`figures/Table_V12_zones.png`) |

Обязательно сохранять выбранную пользователем геометрическую схему и не подменять её автоматически другой схемой при совпадающем числовом коэффициенте. Описание в CSV — подсказка; когда важно направление ветра или положение зон, необходимо смотреть оригинальный эскиз.

**Ограничение:** таблицы приведены в нормализованном виде (каждая ячейка числового результата — отдельная запись), а не в исходной полиграфической форме. Первичная машинная проверка и выборочная сверка таблиц выполнены, но независимая полная посрочная экспертиза не заявляется.
