Рисунок А.2 СП 375: `a=0,10,30,50 м` -> `x=0.25,0.50,0.67,0.67`. Кусочно-линейные функции построены по прямым отрезкам графика, а не взяты как напечатанные формулы СП 375. За 50 м поведение не установлено. Ветровая нагрузка на участке: `w_loc=x*w` (А.1). Рассматривать два отдельных варианта: снижение выше перелома и снижение ниже перелома; не применять снижение к полному сооружению как универсальную поправку.

Формула (48) ЦНИИСК 1978 **не является** формулой рисунка 11.1 СП 20. Структурно спектральные подходы родственны; полностью отождествлять нельзя. В базе расчётов остаётся согласованная простая аппроксимация ξ по Давенпорту с оговорённой погрешностью.
