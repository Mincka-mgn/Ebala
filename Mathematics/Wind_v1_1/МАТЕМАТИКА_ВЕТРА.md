# МАТЕМАТИКА ВЕТРА — Ebala

**Журнал принятых математических зависимостей и инженерных условностей**  
Редакция 1.0 от 06.11.2026. Справочник СП 20 / СП 375 v0.6; расчётная база v0.5.  
Состояние: математическая спецификация для будущего ветрового модуля. **Не означает, что алгоритмы уже реализованы в программе Ebala.**

## 1. Зачем существует этот файл

Документ предназначен для просмотра в окне расчётной программы, для инженера-проверяющего и для будущей ревизии программы. Он отвечает на вопросы: **почему выбран именно этот коэффициент**, какой рисунок или формула является нормативным первоисточником, что было аппроксимировано нами, каковы основания и точность упрощения, где оно перестаёт быть подтверждённым.

**Иерархия:**

1. **NORMATIVE_FORMULA** — формула прямо напечатана в применимом СП.
2. **NORMATIVE_TABLE / GRAPH_READOUT** — число из нормативной таблицы или считывание с рисунка; машинная интерполяция прямых является способом чтения рисунка.
3. **PUBLISHED_ENGINEERING_METHOD** — опубликованная в иностранной технической литературе инженерная функция, использованная для воспроизведения рисунка российского СП; НЕ нормативная формула СП.
4. **OUR_ENGINEERING_APPROXIMATION** — наша аппроксимация или поправка на основе сопоставления с российским рисунком, принятая для автоматизации; НЕ точная физическая тождественная формула.
5. **HISTORICAL_TECHNICAL_CONTEXT** — исторические методы/таблицы, не предназначенные для прямой подстановки в современный расчёт.

При противоречии с действующим текстом СП приоритет имеет СП. Предусмотренные в PROJECT.md предупреждения при выходе за область применимости не должны молча изменять исходные данные.

## 2. Как организованы файлы и что реально подключает расчёт

Весь комплект поставляется **одним ZIP-файлом без вложенных ZIP и без материнской папки версии**. После однократной распаковки:

- **`reference/`** — справочник v0.6: 13 табличных блоков СП 20, 189 строк, графики, аппроксимации и данные СП 375. Основные пути: `reference/data/SP20_wind_all_in_one.json`, `reference/formulas/curved_graphs.json`, `reference/data/straight_graphs.json`, `reference/external/sp375_appendix_a_zonal_factor.json`.
- **`calculations/`** — расчётная база v0.5: формулы раздела 11 и приложения М, расчётные случаи, обозначения, связи и специальные правила СП 375. Основные пути: `calculations/data/formulas.json`, `calculations/data/cases.json`, `calculations/data/special_sp375_rules.json`.
- **`МАТЕМАТИКА_ВЕТРА.md`** — данный журнал решений. Он предназначен для чтения, **не является источником вычисляемых чисел**.
- `README.md` и `PACKAGE_MANIFEST.json` — краткая инструкция и контрольные суммы единой поставки.

Папки `reference/` и `calculations/` функционально независимы, но расчётная база ссылается на справочник по относительному пути `../reference/`. Отдельные архивы для обращения к таблицам больше не нужны. Нормативные коэффициенты и формулы не следует дублировать константами в программном модуле.

В разделах ниже короткие пути вида `verification/...`, `data/...` и `docs/...` приводятся **относительно соответствующей папки** (`reference/` либо `calculations/`), что отмечено в тексте.

## 3. Простые графики приложения В СП 20

Все следующие графики представлены набором *узлов и указанием типа оси*. Это не попытка угадать нелинейную физическую формулу; там, где на изображении нарисованы прямые, соединяем узлы прямыми.

| Рисунок | Аргумент | Как вычисляем ординату | Статус |
|---|---|---|---|
| В.5, сводчатое покрытие | f/l, ось обычная | кусочно-линейная | графическое чтение СП |
| В.6а, купольное покрытие | f/l, ось обычная | кусочно-линейная; выбор кривой по указанным на рисунке параметрам | графическое чтение СП |
| В.14, сфера | Re, ось логарифмическая | линейная по log10(Re) внутри выбранной кривой | графическое чтение СП |
| В.19, призматическое тело | l/d, ось логарифмическая | линейная по log10(l/d) | графическое чтение СП |
| В.23, коэффициент удлинения | λe, ось логарифмическая | линейная по log10(λe) внутри выбранной кривой | графическое чтение СП |

Для линейного участка между узлами `(x0,y0)` и `(x1,y1)`:

`y = y0 + (y1-y0)*(x-x0)/(x1-x0)`.

Для прямого участка на графике с *логарифмической осью x*:

`y = y0 + (y1-y0)*log10(x/x0)/log10(x1/x0)`.

Логарифмическая ось **не означает экспоненциальную зависимость по y**. Логарифмируем только аргумент, не ординату. Не путать интерполяцию **внутри одной кривой** и переход **между отдельными семействами**: последняя допустима только там, где это отдельно предусмотрено нашим правилом и нормативом. Экстраполяцию за график нельзя скрывать.

Реальные узлы и точные диапазоны лежат в `data/straight_graphs.json`; в этом MD они нарочно не продублированы.

## 4. Рисунок В.16: давление по окружности цилиндра

**СП 20, п. В.1.12, рисунок В.16 и таблица В.5.** Для рисунка указана область `Δ/d < 10⁻⁴`. При прочей шероховатости не выдавать модель за проверенное применение рисунка. Угол `β` — градусы от 0 до 180; внутри `sin`, `cos` использовать радианы.

**Окончательно принята болгарская кусочная тригонометрическая функция (PUBLISHED_ENGINEERING_METHOD)** из демонстрационного расчёта по БДС EN 1991-1-4 (Calcpad):

Если `0 <= β <= β_min`:

`cβ = 1 - (1-c_min)*sin(π*β/(2*β_min))²`.

Если `β_min < β <= β_b`:

`cβ = c_b - (c_b-c_min)*cos(π*(β-β_min)/(2*(β_b-β_min)))`.

Если `β_b < β <= 180°`: `cβ = c_b`.

Четыре параметра (`β_min`, `c_min`, `β_b`, `c_b`) для каждой опорной кривой берутся из **таблицы В.5 СП**, а не из «болгарского стандарта». В базе доступны кривые для Re = 5·10⁵, 2·10⁶ и 10⁷. **Не интерполируем между этими тремя кривыми по Re**: выбираем опорную по логарифмическому масштабу; при неопределённости рассматриваем оба целых загружения и оставляем неблагоприятное. Для отсоса неблагоприятнее более отрицательное значение c; для давления — более положительное. Не переключать кривую по отдельным точкам эпюры.

**Почему:** старая наша модель с четвёртой степенью на восходящей ветви сильно расходилась с рисунком (до примерно 0,51 в характерной точке). Болгарская функция лучше воспроизвела кривые по контрольным углам 0°, 30°, 60°, 90°, 120°, 150°, 180°. При пересмотренном отсчёте в 30° по рисунку СП около +0,10, не 0,00, максимальное абсолютное расхождение на 21 контрольной точке порядка **0,06**. Верификация — считывание с напечатанного графика, а не проверка по недоступным авторским численным данным. Степень 4 **не является рабочим алгоритмом**.

Первоисточник приёма: [болгарский расчёт цилиндра, Calcpad, страницы 3–4](https://proektsoft.bg/calcpad/Demo/L4.5.%20%D0%A6%D0%B8%D0%BB%D0%B8%D0%BD%D0%B4%D1%8A%D1%80.pdf). По содержанию там действительно напечатаны обе ветви `sin²` и `cos`; это **расчётный пример**, не собственно текст EN. Контроль: `verification/V16_bulgarian_7_angles.csv` и наложение PNG в справочнике.

## 5. Рисунок В.17: сопротивление цилиндра с шероховатостью

**СП 20, рисунок В.17; аналог EN 1991-1-4, рисунок 7.28.** Вычисляем коэффициент бесконечного цилиндра `c_x∞` от `Re` и `δr=Δ/d`. `δr` НЕ логарифмический декремент затухания сооружения, это относительная шероховатость.

Для `0 <= δr < 0.05` и `Re>0`:

`δeff = max(δr, 1e-5)`;

`c_rough = 1.2 + 0.18*log10(10*δeff)/(1+0.4*log10(Re/1e6))`;

`c_down_SP = 0.11/(1.6*Re/1e6)^1.4`;

`c_x∞ = max(0.4, min(1.2, c_down_SP), c_rough)`.

Если `δr >= 0.05`: `c_x∞ = 1.2` (отдельное плато). Это может дать маленький скачок на границе 0,05, что пока сохранено намеренно. Часть формулы с логарифмом и показатель нисходящей ветви взяты из публикации Еврокода/болгарского инженерного примера. **Число 1,6 — наша эмпирическая поправка** к аргументу `Re` нисходящей ветви для лучшего совпадения с В.17 СП, **не формула, установленная Еврокодом или ЦНИИСК**. Конструкция `max/min` — инженерное соединение участков с границами по рисунку.

**Режим по умолчанию — CONTINUOUS_LOG_ROUGHNESS.** Между 10⁻⁵ и 0,05 подставляем **фактическое** Δ/d без ступенчатого округления; тем самым непрерывно учитывается промежуточная шероховатость. **Альтернативный режим — DISCRETE_CONSERVATIVE_UPPER_COEFFICIENT:** берём из соседних линий ту, что даёт больший `c_x∞` при заданном Re. Например, при `Re=10⁶` и `Δ/d=3·10⁻⁴` непрерывный коэффициент ≈**0,74588**, консервативный ≈**0,84000**.

При `Δ/d <= 1e-5` используем нижнюю опорную кривую; при `Δ/d >= 0.05` — плато из рисунка. Математический знаменатель не должен обращаться в ноль. Проверенный графический диапазон `Re≈10⁴…5·10⁷` уточнять по оригинальному рисунку; за ним выдавать предупреждение. Для конечной длины дальше применяется `c_x=k_λ*c_x∞` по В.23 и таблице В.10 при соответствующих условиях.

**Статус:** сочетание *published Eurocode branches* + *our engineering adjustment*. Ни формула 1,6, ни непрерывное применение к произвольной шероховатости текстом СП не предписаны. Руководство ЦНИИСК 1978, п.5.12, объясняет физику кризиса сопротивления и роль турбулентности, **но не подтверждает численно 1,6**.

Источники: [EN 1991-1-4, рис.7.28](https://www.phd.eng.br/wp-content/uploads/2015/12/en.1991.1.4.2005.pdf); [болгарский Calcpad, стр.6](https://proektsoft.bg/calcpad/Demo/L4.5.%20%D0%A6%D0%B8%D0%BB%D0%B8%D0%BD%D0%B4%D1%8A%D1%80.pdf). Сверки `verification/V17_roughness_modes.csv`, `docs/V17_MODES.md` в справочнике.

## 6. Рисунок 11.1: коэффициент динамичности ξ

**СП 20, раздел 11.1, рис.11.1.** Для одноформового режима вычисляем по принятой нами спектрально мотивированной формуле:

`ξ(Tg1,δd) = sqrt(1 + π²/(3*δd) * Tg1^(2/3)/(1+Tg1²)^(4/3))`.

Здесь `Tg1` — **безразмерный** период по (11.8); `δd>0` — суммарный логарифмический декремент колебаний (это НЕ `Δ/d` шероховатости). **Для промежуточных δd не интерполируем кривые**, а подставляем численное значение декремента прямо в формулу (например, 0,18).

**Причина принятия:** удобно вычислять автоматически без зависимости от пикселей бумажного рисунка. По 24 приблизительно считанным точкам рисунка 11.1 в области `0<=Tg1<=0,30`, `δd=0,15 / 0,22 / 0,30`: максимальная **абсолютная** ошибка ≈`0,0953` по ξ, RMS≈`0,0577`, относительная местами до `5,98%`. Это сопоставимо с точностью ручного считывания графика; пользователем **сознательно принято** как инженерное упрощение. Пример разницы 3,0 против 3,1 даёт порядка 3,3%, однако **не обещаем точность 3% на всём графике**. Результаты за указанным диапазоном с предупреждением, без скрытого ограничения значений.

**Историческая проверка:** в Руководстве ЦНИИСК им. Кучеренко 1978 года, прилож.2, формула (48), опубликована интегральная спектральная модель динамичности. Для **её собственного старого рисунка 6/таблицы 6** интегрирование даёт практически совпадение до сотых (например, при `ε_i=0,25`, `δ=0,15`: таблица 2,93, интеграл ≈2,928). В сравнении с приблизительными точками современного рис. 11.1 историческая модель дала максимальное абсолютное расхождение ≈0,113 против 0,095 у нашей простой функции. Это полезная **теоретическая поддержка физического подхода**, но **не доказательство математической тождественности рисунка 11.1 формуле (48)**. Из-за малой практической выгоды интегральный решатель вместо простой формулы не вводим.

Важное исключение: **таблица 11.5 для предельного периода `Tg_lim` остаётся отдельной таблицей**. Непрерывная ξ не позволяет автоматически выводить неизвестную нормативную интерполяцию Tg_lim между тремя декрементами. Расчёт по нескольким формам и приложение М этим выражением не заменяются.

Контроль в расчётной базе: `11.1.xi_davenport_approx`, `verification/figure_11_1_approximation_vs_print.csv`, `docs/FIGURE_11_1_APPROXIMATION_DECISION.md`.

## 7. СП 375.1325800.2023: специальные решения для дымовых труб и башен

**Важно:** СП 375 — отдельный специальный норматив с собственной областью применения и исключениями (п.1.1–1.2), не универсальная поправка к ветру на любое здание. Применимые общие аэродинамические коэффициенты по СП20.

### 7.1. Коэффициент надёжности по ветровой нагрузке

Таблица 7.1 СП375 (печ. с.16):

| Тип | H | γf |
|---|---|---|
| Общий случай труб | H<150 м | 1,4 |
| Общий случай труб | 150≤H≤300 м | 1,5 |
| Общий случай труб | H>300 м | 1,6 |
| **Стальные трубы и башни, примечание 3** | H≤100 м | 1,4 |
| **Стальные трубы и башни, примечание 3** | 100<H≤210 м | 1,5 |
| **Стальные трубы и башни, примечание 3** | H>210 м | **назначать по заданию на проектирование** |

**Почему так выбираем:** специальное примечание 3 уточняет общее правило таблицы для стальных труб и башен. Не разрешается молча подменять «по заданию» числом из общего ряда. Машинный источник: `data/special_sp375_rules.json` расчётной базы.

### 7.2. Зональное действие ветра, приложение А

Только при расчёте раскосов и распорок решётчатой башни с **переломом поясов**. Рис. А.1 задаёт **два отдельных загружения**, при которых снижается нагрузка либо выше, либо ниже перелома. Нормативная формула (А.1): `w_loc = x*w`, где `w` — расчётная нагрузка. Коэффициент `x` нормативно берётся **по рисунку А.2** в зависимости от длины участка `a`, м.

По прямолинейным участкам графика принята кусочно-линейная зависимость (машинные узлы в **справочнике**, `external/sp375_appendix_a_zonal_factor.json`):

- `0≤a≤10`: `x=0.25+0.025*a`;
- `10<a≤30`: `x=0.50+0.0085*(a-10)`;
- `30<a≤50`: `x=0.67`.

**Статус:** это аппроксимация **прямых отрезков нормативного рисунка**, не отдельно выписанная формула СП. За `a>50 м` рисунок не подтверждает значения: нельзя без предупреждения переносить плато дальше. Для обоих вариантов берётся огибающая усилий **в раскосах/распорках**, не автоматически «худшая» величина ветра на всей башне. Ветвления в базе `SP375_TOWER_ZONAL_WIND` пока не реализованы в программе.

### 7.3. Вихревое возбуждение и усталость

П.6.2 требует для цилиндрических труб и труб небольшой конусности (уклон до 1,2%) расчёт резонансного вихревого возбуждения и вызванной им усталости. Это **флаг обязательной отдельной проверки**, а не готовый алгоритм: методика и численный решатель усталости в текущем пакете не реализованы. Ветровой модуль Ebala не должен выдавать положительный вывод по устойчивости трубы из одного только подсчёта ветрового давления.

## 8. Что дали дополнительные источники и чего они НЕ дали

- **Руководство ЦНИИСК (1978)**: опубликован интеграл (48), старая таблица динамичности для независимой проверки, физическое описание кризиса обтекания цилиндров, данные для градирен/близких цилиндров. Это **историческая техническая литература** к СНиП II-6-74. Не имеет статуса действующей формулы СП20 и не доказывает выбранную поправку 1,6.
- **СП 375.1325800.2023**: действующие в его области специальные ветровые правила по коэффициентам надежности, зональному ветру и необходимости проверки вихревого резонанса/усталости. Не распространять на обыкновенное здание без проверки применимости.
- **СП 43.13330.2012**: упоминается в СП375 для труб (в частности, п.9.3). В этой редакции пакета **не переносились** дополнительные конструктивные алгоритмы СП43, поскольку модуль Ebala определяет нагрузки, а не рассчитывает прочность трубы.

## 9. Исправления, которые нельзя потерять при интеграции

- (М.11): `Delta2_k = (1-(f_spectral/f_k)²)² + gamma_k*(f_spectral/f_k)²` — `gamma_k` **не возводить в квадрат**.
- (М.18): `xi_s_squared <= (1+epsilon_D)*v0_squared`, причем `v0_squared` из (М.20) **безразмерная** величина, не `V0²` со скоростью ветра.
- На нормативных рисунках `f` может обозначать и стрелу подъёма, и частоту; машинно `f_rise` [м] и `f_spectral` [Гц]. Не использовать неоднозначный ID `f`.
- В.16: проверенная область `Δ/d<10⁻⁴`, не ошибочно указанное когда-то `5·10⁻⁴`.
- Динамическая ξ не заменяет многомодальный расчёт приложения М, а передача нагрузок на конструкции не является поверкой их прочности.
