# Ebala — математика ветровых нагрузок

**Единый комплект v1.1** (06.11.2026). Один ZIP, без других ZIP внутри.

Распаковать ОДИН раз. Содержимое корня:

```
reference/                  нормативные таблицы, графики, аппроксимации (v0.6)
  data/
  formulas/
  external/
  figures/
  docs/
  verification/
  tests/
calculations/               формулы, сценарии и специальные расчётные правила (v0.5)
  data/
  docs/
  samples/
  verification/
  tests/
  tools/
МАТЕМАТИКА_ВЕТРА.md       обоснование выбранных зависимостей
README.md                  этот файл
PACKAGE_MANIFEST.json      список всех файлов и контрольные суммы
```

Нормативные таблицы берутся из `reference/`; расчётные процедуры используют `calculations/` и обращаются к `../reference/` по ссылкам из `calculations/data/reference_linkage.json`. Данные разделены логически, но не упакованы отдельными архивами.

Содержимое нормативных таблиц и формул перенесено из справочника v0.6 и базы v0.5 без изменения численных зависимостей. Внесены только изменения относительных путей, инструкции и тесты расположения файлов. Два вспомогательных дубля `docs/МАТЕМАТИКА_ВЕТРА.md` исключены; актуальный журнал решений лежит один раз в корне.

Для проверки (Python 3, запуск из распакованной папки):

```
python reference/tests/verify_reference.py
python calculations/tests/verify_database.py
```

Взаимосвязь описана в `calculations/data/reference_linkage.json`. Программа Ebala этим комплектом не изменяется; базы являются спецификацией для будущего ветрового модуля.
