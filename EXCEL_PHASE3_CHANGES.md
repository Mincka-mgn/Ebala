# Ebala — Excel, контрольная точка этапа 3

**Основа:** исходники этапа 2 (Ebala 0.52 + этапы 1–2). Это **не новая версия программы**.
**Охват:** Excel собственного веса, временных, транспортных и крановых нагрузок, местности и общей ведомости.
**Сборка:** Windows EXE не создавался; Go-тесты и экспорт изменённого кода не запускались.

## Изменения исходников

1. **Общая ведомость:** основной лист теперь содержит ссылки на формульные листы для собственного веса, временных, транспорта и колёс мостовых кранов. Набор исходных листов отделён от итоговой сводки.
2. **Главный путь экспорта:** `selectedReport()` передаёт снимок принятых параметров местности. До изменения путь с главного экрана терял структуру Site, в отличие от экспорта из модуля временных нагрузок. После создания снимка дальнейшая правка проекта не изменяет исходные данные уже подготовленного отчёта.
3. **Местность:** `excel_phase3_site.go` выводит отдельный лист принятых параметров, не подменяя их готовыми значениями расчётных коэффициентов.
4. **Собственный вес:** лист «Собственный вес - исходные» содержит доступную геометрию сохранённых слоёв (толщина, плотность, γf) либо напрямую введённую нагрузку; на листе расчёта нормативные/расчётные нагрузки вычисляются формулами. Для старых записей, в которых исходные слои отсутствуют, нельзя выдумывать геометрию: используется известная принятая нагрузка.
5. **Временные нагрузки:** сохранены типизированные поля нормативного значения, грузовой площади, количества перекрытий и класса снижения. Класс уточняется по точному коду позиции каталога, а не по совпадению префикса.
6. **Транспорт:** расчётные листы содержат формулы для реализованных схем АК, НК, АБ, СК, метро и трамвая. Справочные железнодорожные интенсивности не объявляются полноценным расчётом по линии влияния.
7. **Краны:** в общую ведомость добавлены раздельные листы принятого паспорта, колёсных нагрузок/координат и арифметических преобразований. Даже при отсутствии дополнительных полей паспорта сведения о принятом кране остаются доступными.
8. **Отдельная расстановка кранов:** численно найденные координаты положения остаются входным исключением; усилия и ординаты линии влияния задаются Excel-формулами через метод трёх моментов. Сама интеграция этого расчёта в общую ведомость остаётся незакрытой.
9. **Оформление и безопасность:** приоритет паспортного листа кранов среди исходных вкладок, заголовки A1 «На этом листе…», безопасная запись пользовательских строк, начинающихся с `=`.
10. **Подготовлены регрессионные тесты:** `excel_phase3_contract_test.go`, `excel_phase3_mainpath_test.go` для принятых параметров, источников, ссылок и отсутствия формульной интерпретации пользовательского текста.

## Что НЕ закрыто и НЕ считается выполненным

- Общая ведомость **расстановок кранов** всё ещё содержит значения усилий, переданные из Go. Это не разрешённое численное исключение, пока расчёт влияния не вынесен в формулы той же книги. Отдельный XLSX расстановок математически детализирован, но не заменяет общий экспорт.
- Отдельные старые экспортные пути (в том числе `ExportExcel` для проектов вне управляемой ведомости) ещё не переведены на общий контракт.
- Модули местности и сейсмики требуют проверки того, что редактирование принятых исходных данных обновляет **все** производные значения.
- Топология снеговых вариантов и резерв полярной сетки не полностью динамические; особые случаи гололёда и интерполяция вне таблиц требуют отдельного контроля.
- Выбор «Включить в общий отчёт» из `PROJECT.md` ещё не представлен устойчиво в модели сохранённых блоков. Этот вопрос относится также к хранению/GUI, поэтому не был самостоятельно перестроен при Excel-этапе.
- Нет независимой численной аттестации всех вариантов, проверки OOXML из **новых** исходников и пересчёта в Microsoft Excel.

## Поверка

- Все изменённые Go-файлы пропущены через `gofmt`.
- Статически сверены ключевые пути: источник → формульный лист → общая ведомость; `selectedReport()` → снимок местности → входной лист Excel.
- Проверено, что не было изменений `PROJECT.md`, в ядре расчёта снега/гололёда или Windows GUI.
- **Не запускались** `go test`, `go build`, новая генерация файлов и Microsoft Office. Эти проверки предстоят на следующем этапе.
