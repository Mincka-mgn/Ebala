Ebala 0.42 — перечень изменений и проверок

1. Отчёты и файлы
- Новое окно уведомления после успешного сохранения с кнопками «ОК» и «Открыть сохранённый файл»; исключён прежний системный диалог, связанный с аварийным завершением.
- Обычный существующий файл перезаписывается; индекс (1), (2) назначается только после системного сообщения о блокировке файла.
- Добавлена настройка сохранения: последняя использованная папка либо постоянная папка; настройка сохраняется между запусками.
- Сохранение проекта и его открытие перенесены в главное окно.

2. Модули
- При первом использовании снеговой район VIII (Sg=4,0 кПа), гололёдный район IV (b=15 мм); значения доступны для изменения.
- В снеговом модуле явно создана кнопка «Горные районы», ведущая к уже существующим настройкам местности.
- Специальные условия расчёта можно открывать до заполнения обязательных полей.
- Неинформативные сообщения об отсутствии полей заменены названиями параметров.
- Увеличена площадь изображения геометрии снегового покрытия.
- Для конического и сферического резервуара к разрезу добавлен вид сверху с сектором β.
- В окне местности изменения значений автоматически учитываются без отдельной кнопки сохранения параметров.

3. Состав общего отчёта
- Выполненные расчёты собственного веса, снеговых и гололёдных нагрузок автоматически появляются в составе отчёта.
- Для них реализовано сохранение текущего расчёта с редактируемым именем и переход к следующему; пустое имя разрешено.
- Добавлена команда сброса текущей нагрузки, не затрагивающая другие сохранённые расчёты.
- Сохранение нескольких самостоятельных расчётных блоков в проекте и их отдельный экспорт.
- При перестановке записей ведомости выбранная запись сохраняет выделение.
- Добавлено переименование расчётного блока.

4. Документы Word
- Формулы снеговой нагрузки вынесены в отдельные центрированные строки.
- Заголовки поясняют нормативную, расчётную и пониженную нормативную снеговые нагрузки.
- Для резервуаров в Word используется компактная таблица по радиусу r и углу β с объединением нулевых секторов.
- Полная детализация расчётной сетки сохраняется в Excel.
- Нормативные ссылки записываются как «СП 20.13330.2016».
- Окно «О программе» содержит одно полное название обычным шрифтом.

Проверки
- GO111MODULE=off go test ./... -count=1 — PASS.
- Кросс-компиляция Windows amd64 GUI — PASS.
- Сгенерированы и визуально просмотрены два Word-отчёта (снег/резервуар и общий отчёт).
- Сгенерированы две книги XLSX, их XML проверен на синтаксическую корректность, отсутствие повторяющихся ячеек и нарушение порядка строк.
- Проверены автоматическое включение нагрузок в проект, обновление записей, сохранение пустого названия, сценарии совпадения имени файла.

Не подтверждено в данном окружении
- Реальный запуск окон на Windows и поведение при системной блокировке Excel/Word на машине пользователя.
- Открытие файлов непосредственно в Microsoft Excel (проверка структуры XLSX не заменяет проверку в приложении).
- В некоторых других модулях, кроме собственного веса, снега и гололёда, механизм нескольких независимых расчётов по кнопке «новый расчёт» не был полностью переработан.
