# Ветровая нагрузка в Ebala 0.58

Ebala 0.58 заменяет ввод нагрузки в одной отметке построением эпюры давления по высоте. Это **первая очередь**, не полный охват ветровых случаев СП 20.13330.2016.

## Работа в программе

1. Откройте «Ветровая нагрузка». Если местность не настроена, новый расчёт использует **максимальный ветровой район VII**. В выпадающем списке можно назначить другой район вручную.
2. Выберите тип местности А, В или С. Команда «Взять из местности» переносит только район и тип местности. Если любой из этих параметров отсутствует в разделе «Местность», команда открывает его для заполнения.
3. Выберите единицы нагрузки: **кПа** или **кгс/м²**. Выбор влияет на весь ветровой расчёт, итоговые цифры и отчёты.
4. В едином списке выберите **тип сооружения и поверхность** (для выбранной схемы нормативный аэродинамический коэффициент определяется автоматически). Если подходящая нормативная схема пока не реализована, доступен ручной ввод `c` с предупреждением.
5. Задайте размеры по рисунку: `h` — высота сооружения, `d` — размер здания по направлению ветра, `b` — ширина рассматриваемой вертикальной поверхности. `d` не нужен для отдельно стоящей стены. Для пульсационной составляющей коэффициент корреляции определяется по `ρ=b`, `χ=h`.
6. Выберите «Пульсации без ввода частот» или «Только средняя составляющая». Расчёт с вводом собственных частот пока исключён из интерфейса. Кнопка «Что такое декремент δ?» поясняет его нормативные значения для будущей динамической очереди; вводить δ не требуется.
7. Нажмите **«Рассчитать и построить эпюру»**. Откроется вкладка результатов. На графике показаны нормативная и расчётная нагрузки по высоте; справа приведены численные ординаты, ниже — сводка и предупреждения.
8. Расчёт автоматически сохраняется в ведомости. Из результатов доступны отдельные **DOCX** и **XLSX**, а также команда «Сохранить в ведомость и новый».

## Нормативные данные и расчёт

Числа таблиц 11.1–11.6, коэффициенты приложения В и математические формулы загружаются из `WindData/*.json`. Проверяется контрольная сумма по манифесту. Принятый способ `k(z)` — **таблица 11.2**. Формула 11.4 в некоторых промежуточных точках расходится с табличной интерполяцией, поэтому без отдельного согласования она не подставляется вместо таблицы.

Эпюра строится многократным вызовом уже проверенного ядра на каждой высоте, с учётом границ высотных зон. В Excel каждый узел воспроизводится формулами по данным из листов нормативной базы, независимо от сохранённых чисел Go. Внутренние значения в Па; округление только при отображении.

## Ограничения

Поддерживаются отдельные поверхности и зоны схем В.1 и В.2, а не весь набор аэродинамических коэффициентов СП. Автоматическая пространственная комбинация ветрового давления, полный динамический расчёт, вихревое возбуждение, пиковая нагрузка и приложение М ещё не реализованы. Отдельные варианты для разных поверхностей создаются самостоятельно. Подробнее в `CHANGES_0.58.txt`.

## Сборка и контроль

Приложение остаётся однопакетным Go/Win32 без `go.mod`. Go-тесты: `GO111MODULE=off go test -count=1 .`. Windows GUI x64: `GOOS=windows GOARCH=amd64 GO111MODULE=off go build -ldflags="-H=windowsgui -s -w" -o Ebala_0.58.exe .`.

Полная математическая спецификация с документацией и контрольными примерами включена **только в исходники**, в папку `Mathematics/Wind_v1_1`. Рабочей Windows-программе необходимы JSON базы и поясняющие изображения, входящие в рабочий ZIP.
