# Ebala 0.60 — незавершённый этап 1

Это **исходники**, а не готовый выпуск. На основе 0.59 выполнены исправления интерфейса и ошибки определения эквивалентной высоты по СП 20.13330.2016. Подробности — в `CHANGES_0.60_STAGE1.txt` и `QA_0.60_STAGE1.txt`.

* Для зданий `B` — длина вдоль конька, `L` — поперечный размер (ширина), `H` — отметка конька, `h` — подъём двускатной крыши. Для сравнения с п. 11.1.5 СП при ветре вдоль конька `d=L`, при ветре поперёк конька `d=B`.
* На этом этапе для здания считаются только стеновые зоны В.2. Скаты крыши пока **не рассчитаны**.
* Эпюра может быть ступенчатой вследствие нормативного определения `z_e` для зданий. Визуально сглаживать эти ступени без согласования изменения методики нельзя.
* Изображения фасадов в SVG — авторские схемы интерфейса, изображения/цифры в нормативных JSON не изменены.

**Дальнейшая команда пользователя нужна для этапа 2:** реализация В.3а и В.3б (все зоны и альтернативные знаки), отображение крыши на плане, DOCX/XLSX и приёмка. Только после этого может быть выпущен отдельный Windows-архив.
