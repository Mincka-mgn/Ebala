# Ebala 0.62 — ветровая нагрузка

Ebala — автономная Windows x64 программа для определения нагрузок на один
объект обследования. В этой версии переработаны схемы ветра и отчёт Word;
нормативная математика поддержанных случаев сохранена.

## Применение

1. В разделе «Ветровая нагрузка» выберите сооружение и его геометрию.
2. Укажите ветровой район либо базовое давление вручную, тип местности и
   режим учёта пульсаций.
3. Нажмите «Рассчитать» и просматривайте направления, поверхности, зоны и эпюры.
4. Сохраните расчёт в ведомость. DOCX предназначен для инженерного заключения,
   XLSX — для подробной независимой проверки промежуточных расчётов.

## Реализовано

- Стены прямоугольного здания, отдельно стоящая стена, двускатная кровля.
- Ветер вдоль и поперёк конька; нормативные зоны и альтернативные знаковые
  варианты кровельных коэффициентов.
- Отображение зон, реальные размеры и условный разрыв длинных участков.
- Кровельные варианты не создаются при h=0.
- Базовый расчёт, поддержанная упрощённая пульсационная составляющая.
- Запись результатов в проект, общий DOCX и независимый XLSX.
