## Реально исправлено

1. `snow_excel_sector_phase9.go`: устранена ошибка `fmt.Sprintf` с несовпадением 15 спецификаторов `%s` и 14 аргументов. Прежний код не проходил компиляцию тестов. Формула высоты составлена из именованных частей геометрии, без неоднозначного списка форматных аргументов.
2. `excel_phase4_crane_placements.go`: исправлено переименование листов в объединённой крановой книге. Отдельный генератор уже кодирует апострофы как `&#39;`, поэтому прежний поиск только буквальных `'Исходные данные'!`, `'Балка'!` и `'Колёса'!` **не срабатывал**. Теперь обрабатываются обе формы. Контрольный XLSX проверен повторной генерацией: формулы Р01 используют `Р01 Вход`, `Р01 Балка`, `Р01 Колёса`; старые ссылки отсутствуют.
3. Добавлен `TestExcelPhase10CraneEscapedReferences`, предотвращающий повторение ошибки ссылок. Добавлен управляемый переменной среды `EBALA_QA_DIR` генератор контрольных XLSX `TestExcelPhase10Fixture`; без переменной тест пропускается и ничего не пишет в произвольные пути.
4. Уточнены устаревшие контрактные тесты предшествующих этапов: они проверяют существующую цепочку `Нагрузки → Перечень загружений → Вариант`, HTML/XML-экранирование, резервные варианты и современный формат числовых листов вместо несуществующих старых адресов и названий. Отдельно исправлена ложная проверка `0/1`, которая срабатывала на законное выражение `K10/1000`.

- `GO111MODULE=off go test -count=1 -timeout=240s ./...` — результат фиксируется отдельно в `EXCEL_PHASE10_QA.md`; запуск выполнен на Linux, без Windows EXE.
