Ebala 0.57 — первый рабочий выпуск самостоятельного модуля ветровой нагрузки
06.11.2026

База: Ebala 0.56 Stage 1. Согласованная математика: Ebala_Wind_Mathematics_v1_1.

РЕАЛИЗОВАНО
- Самостоятельная библиотека расчёта ветра на Go (wind_engine.go), изолированная от вычислений остальных модулей.
- Проверка SHA-256 нормативных JSON; сохранение контрольной суммы, идентификаторов формул и ссылок СП 20.13330.2016 в результатах проекта.
- Базовое нормативное давление из таблицы 11.1 или ручное значение; типы местности А/В/С; эквивалентная высота для зданий и башенных сооружений; k по таблице 11.2 или формуле 11.4; средняя составляющая по формуле 11.2.
- Аэродинамические коэффициенты некоторых зон схем В.1 и В.2 из нормативного JSON; возможность ручного ввода c (с явной фиксацией источника).
- Пульсационная составляющая без резонанса по формуле 11.5 с табличными ζ, ν; упрощённая динамическая ветвь по 11.7, 11.8, 11.9а и зафиксированной в JSON аппроксимации ξ рис. 11.1; сообщения о применимости и о неутверждённой в СП интерполяции ν.
- Отдельный Win32-экран «Ветровая нагрузка», расчёт, сохранение и повторное редактирование именованных блоков в общей ведомости.
- Включение блоков ветра в общий DOCX и XLSX; экспорт отдельного DOCX; независимый XLSX с исходными данными, нормативными таблицами и формулами Excel (а не подставленными результатами Go).
- Математическая документация и оригинальная иерархия архива помещены в Mathematics/Wind_v1_1 полного архива исходников. В рабочем архиве находятся только необходимые расчётные JSON (папка WindData), а не исследовательский архив.

ГРАНИЦЫ РЕАЛИЗАЦИИ
- Это первый этап ветрового модуля, а НЕ реализация всех 27 объявленных в математическом архиве случаев.
- Из приложения В через интерфейс доступны только поддержанные коэффициенты по схемам В.1 и В.2; остальные формы зданий, ограждения, цилиндры и специальные коэффициенты НЕ реализованы. Для других расчётов доступен явный ручной c.
- Один расчётный блок соответствует одной высотной зоне/отметке и одному аэродинамическому коэффициенту; пространственные схемы и интегральные усилия автоматически не строятся.
- Динамическая ветвь является локальной реализацией указанных выражений, не заменяет модальный расчёт сооружения и не реализует приложение М СП 20.13330.2016.
- Пиковые нагрузки, вихревое возбуждение, усталостные проверки и специальные расчёты по СП 375.1325800.2023 не реализованы.
- Для интерполяции таблицы 11.6 применяется билинейная интерполяция с явно выводимым предупреждением об отсутствии прямого нормативного предписания способа; для ξ применяется утверждённая в математическом архиве аппроксимация с предупреждением.
- Работоспособность GUI на физической машине Windows, открытие DOCX в Microsoft Word и XLSX в Microsoft Excel в этой среде НЕ ПРОВЕРЯЛИСЬ; выполнены сборка и структурные тесты форматов.

КОНТРОЛЬ И ПРОВЕРКИ
- Контрольный пример: w_m=258,4 Па; w_p=192,55968 Па; w_n=450,95968 Па; w_d=631,343552 Па.
- Тесты 0.57: давление, высотные зоны, схемы В.1/В.2, ручной коэффициент, динамическая аппроксимация, контроль целостности базы, сохранение блоков, DOCX/XLSX.
- Общий регрессионный тест Go (264 пройденных теста), отдельные семь проверочных скриптов математической базы.
- Кросс-компиляция Windows x64 с -ldflags="-H=windowsgui -s -w"; проверка PE Subsystem = Windows GUI.
- Ручная приёмка на Windows и независимое сопоставление XLSX с Go для дополнительных комбинаций входных данных остаются задачами следующей проверки.
