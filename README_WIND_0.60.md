# Ebala 0.60 (бета) — ветер, этап 2

Реализован расчёт стен и двускатной кровли по СП 20.13330.2016.

## Запуск
Распакуйте **весь** Windows-архив в одну папку и запустите `Ebala_0.60.exe`.
Не отделяйте EXE от каталогов `WindData`, `Resources`, `Catalog`, `Databases`, `Maps`.
Приложение предназначено для Windows x64, без установки Go.

## Интерфейс
Задайте ветровой район/ручное базовое давление, тип местности, L, B,
высоту конька H и подъём крыши h. Шаг ординат по умолчанию 2,5 м.
Кнопка расчёта определяет два направления: вдоль и поперёк конька.
В каждом направлении отображаются все существующие зоны стен и крыши.
Выберите направление, поверхность и, при необходимости, знаковый вариант.
В плане отмечается соответствующая зона. Расчётные результаты сохраняются
единым именованным блоком проекта; в отчётах раскрываются все поверхности.

## Крыша
- Вдоль конька: В.3б, зоны F–I.
- Поперёк конька: В.3а, зоны F–J.
- В табличном интервале с двумя ветвями В.3а программа сохраняет оба полных
  варианта (наборы всех зон), а не выбирает поштучно максимум/минимум c.
- β определяется по геометрии, c и границы углов считываются из нормативных JSON.
- Давление на кровлю вычисляется на уровне конька H; зональные площади
  определяются согласно рисунку В.4.

## Экспорт
DOCX содержит фактические величины расчёта из Go и нормативные ссылки.
В XLSX коэффициенты и нагрузки рассчитываются независимо формулами Excel:
принятые исходные величины на отдельных листах, нормативные таблицы в книге.
Один экспорт содержит все рассчитанные ветровые зоны и знаковые варианты.

## Важные ограничения
1. Утверждённый метод расчёта пульсационной составляющей работает с
   прямоугольной проекцией зоны в плане xoy. Для наклонных скатов показывается
   предупреждение о необходимости проверить применимость такой модели.
2. При нестандартном уклоне за пределами нормативной таблицы программа
   не придумывает коэффициент и не выполняет экстраполяцию.
3. Если вручную поменять в XLSX геометрию так, что исчезают или появляются
   целые зоны или знаковые варианты, книгу следует сформировать заново.
4. Полная динамика с частотами, пиковая нагрузка и специальные сооружения
   не входят в эту версию.
5. Кросс-сборка Windows получена; интерактивный GUI и Microsoft Office
   в данной среде не проверены.

Изменения и выполненные проверки: `CHANGES_0.60.txt`.
Математическая документация и тесты включены в архив исходников.
