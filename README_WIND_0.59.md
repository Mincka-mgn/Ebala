# Ветровые нагрузки в Ebala 0.59

Модуль предназначен для инженерного определения распределения ветрового давления по высоте **стен** прямоугольного здания или отдельно стоящей стены. Это рабочая первая очередь, **не полный расчёт здания вместе с двускатной крышей**.

## Порядок работы

1. Выберите ветровой район и тип местности или нажмите «Взять из местности». Если местность не настроена, программа открывает её раздел. При отсутствии заданных данных используется VII ветровой район.
2. Выберите единицы кПа или кгс/м². Выбор относится ко всей форме, результатам и отчётам.
3. Выберите **«Здание»** либо **«Отдельно стоящая стена»**.
4. Для здания введите длину `d`, ширину `b`, высоту до конька `H`, подъём двускатной крыши `h`. Схема «домик» поясняет только размеры. Коэффициенты нагрузки на скаты в версии 0.59 не рассчитываются. Для стены нужны общая длина `b` и высота `H`.
5. В поле «Шаг эпюры» оставьте «Авто» для отметок 0; 5; 7,5; 10 ... H либо задайте своё положительное число (м). В ручном режиме интервалы не превышают заданного шага, узлы 0, 5 (если H≥5) и H обязательны.
6. Нажмите «Рассчитать все зоны». Для здания вычисляются направления +X, −X, +Y, −Y, а внутри направлений все существующие зоны В.2; для стены рассчитываются зоны В.1. В результатах выберите **направление**, затем **зону**. Соответствующие схема, эпюра, коэффициент и численные точки обновятся без нового расчёта.
7. Для положительных нагрузок ось давления расположена справа от нуля, для отсоса — слева; эпюра не сглаживает скачки кусочного расчёта.
8. По кнопкам «Отчёт DOCX» и «Расчёт XLSX» выгружается **весь набор рассчитанных зон**, а не одна показанная зона. Ведомость хранит один именованный блок для всей геометрии.

## Принцип расчёта

Формулы, коэффициенты и нормативные таблицы непосредственно загружаются из `WindData`, математическое ядро является прежним утверждённым Go-кодом. Зоны вычисляются по геометрии нормативных схем В.1 и В.2 (здание — рисунок В.3). Один и тот же нормативный коэффициент используется независимо от отображения, Word и Excel. XLSX содержит самостоятельные формулы.

**Не суммируйте давления разных поверхностей и альтернативных направлений как отдельные независимые нагрузки.** Это пространственные загружения.

В интерфейсе не запрашиваются частоты; пульсации по формуле 11.5 не имеют подтверждения условия f₁>f_lim без динамических характеристик. Предупреждение показывается инженеру, не выдаётся за проверенное условие.

## Сборка

`GOOS=windows GOARCH=amd64 GO111MODULE=off go build -ldflags="-H=windowsgui -s -w" -o Ebala_0.59.exe .`

Приложение запускается из распакованной папки. Сохраняйте каталоги `Catalog`, `Databases`, `Maps`, `Resources`, `WindData` рядом с EXE.

**Обозначения на рисунке В.3:** нормативное `h` относится к высоте здания; в интерфейсе этого модуля она обозначена `H`. Буква `h` на отдельной картинке двускатной крыши означает исключительно подъём кровли, который пока не используется в расчётах стеновых коэффициентов.
