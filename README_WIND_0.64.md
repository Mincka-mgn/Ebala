# Ветровая нагрузка в Ebala 0.64

Основа расчётов — СП 20.13330.2016 и неизменные нормативные JSON математической базы Wind_v1_1.

## Вывод

**Word** содержит общую методику, схемы с размерами, отдельные направления ветра, зональные результаты. В новых заголовках зоны F указаны количество угловых участков и действительные ширина/протяжённость одного участка. На схемах торцы D и E подписаны, стрелки ветра отодвинуты.

**Excel** содержит в первом листе «Исходные данные» полное оглавление с номерами зональных расчётов и активными ссылками. Далее следуют красные листы исходных данных, синие расчётные, зелёные итоговые и эпюры; нормативные таблицы с префиксом «СП» в конце выделены серым. Ширина и протяжённость зон вычисляются формулами книги по исходным размерам B и L. «Итоговые нагрузки» содержит конечные значения и ссылки на расчёты.

## Пульсация

Режим «Пульсация для невысоких массивных зданий» показывает дополнительный выбор конструктивной системы и логарифмический декремент δ. Нормативное значение берётся из таблицы 11.5 базы по типу сооружения (0,15, 0,22 или 0,30); инженер может исправить значение. **Формула (11.5) не зависит от δ**, поэтому данное поле не влияет на результаты упрощённого расчёта. Для проверки динамики по собственной частоте необходим другой, пока не реализованный метод расчёта.

Отдельный режим «Не учитывать пульсацию» скрывает конструктивную систему и δ, а также не включает вычисления ζ/ν в Excel. Это выбор инженера, не автоматическое разрешение СП.

## Файлы и сохранение

При выборе существующего имени DOCX/XLSX стандартный Windows-диалог должен запросить подтверждение перезаписи. При блокировке файла программа сообщает об ошибке, не создавая молчаливо файл `(1)`.

Системные ограничения и протокол: `QA_0.64.txt`; изменения: `CHANGES_0.64.txt`. Проверка Win32-интерфейса на реальной Windows остаётся незавершённой.
