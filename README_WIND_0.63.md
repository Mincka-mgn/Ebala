# Ebala 0.63 — ветровая нагрузка

Ebala — автономное приложение Windows x64 для определения нагрузок на здание
или сооружение с формированием готового инженерного DOCX и подробного независимого XLSX.

## Обновлено по замечаниям к 0.62

- Поясняющий план подписан «План здания. Ветер вдоль/поперёк конька».
- Каждая стрелка направления снабжена словом «Ветер» непосредственно рядом.
- На планах с двускатной кровлей показан сплошной конёк с подписью; при h=0
  конёк и кровельные расчётные варианты отсутствуют.
- Стеновые зоны A/B/C показаны линейными участками стен, D/E не смешиваются
  с ними, кровельные F/G расположены со стороны наветренного карниза.
- На схемах Word и GUI подписаны фактические размеры по двум направлениям.
  Разрывы масштаба полностью отменены.
- Ширина зоны — поперёк ветра; протяжённость — вдоль ветра. Для линейных
  участков стен не назначается фиктивная ширина на плане.

## Применение

В модуле «Ветровая нагрузка» задайте геометрию и исходные данные, нажмите
«Рассчитать» и выберите направление и зону на странице результатов.
«Отчёт Word» формирует краткий расчётный раздел для заключения,
«Отчёт Excel» — подробную формульную проверку.

Нормативная база JSON не изменена. Потребуется окончательная визуальная
проверка GUI на реальном Windows и пересчёт XLSX в Microsoft Excel.
Подробные результаты проверок: `QA_0.63.txt`.
