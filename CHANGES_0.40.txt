Ebala 0.40 — перечень изменений и границ проверки

1. Модуль гололёда: галочка «ветер» удалена, расчёт выполняется при выбранном ветровом районе. В выпадающем списке имеется явно обозначенный вариант «без ветра». Выбор гололёдного района немедленно подставляет толщину из таблицы 12.1, отдельная кнопка «Применить район» удалена.
2. Поле коэффициента аэродинамического сопротивления Cx видно всегда и допускает ввод любого положительного нормативно допустимого значения (0<Cx≤10 валидации); кнопка «Сброс Cx» возвращает типовое значение. Для проводов и тросов используется Cx=1,2 по п. В.1.12 СП 20.13330.2016. Для прочих форм 1,2 — предварительное значение, пользователь должен проверить его по приложению В.
3. Тип местности ветра А/В/С снабжён расшифровкой, А используется по умолчанию при отсутствии подтверждённых данных. Ветровой район, если определён в модуле местности, наследуется из него.
4. Плотность 900 кг/м³ сохранена по умолчанию. В специальных условиях добавлена отдельная кнопка сброса 900. Переработаны описания вводимых характеристик, раздел переименован в «Специальные условия расчёта»; исправлено наложение признака гибкости на плотность.
5. Возврат из параметров гололёда и из модуля местности возвращает в вызвавший расчётный модуль. Удерживаются введённые исходные данные. Отдельно исправлено изменение местности при возвращении из снега.
6. В модуле снега добавлена кнопка «Горные районы». Она открывает существующий модуль местности на процедурах выбора горной территории, абсолютной отметки и справочного поиска высоты. Расчёт использует Project.Site.EffectiveSnow() из единого исходного значения. Если пользователь не изменил горные данные, существующий ручной снеговой ввод не отменяется.
7. Кнопки расчёта и экспорта в гололёдном модуле перемещены вниз. Экспортные кнопки называют «Отчёт Word» и «Расчёт Excel»; снеговая кнопка переименована аналогично.
8. Word гололёда: названия входных данных полностью расшифрованы, ветровой район с нормативным давлением, тип местности с пояснением, обозначения отдельными строками с жирным обозначением, результаты разделены на вертикальную и горизонтальную нагрузки. Удалены повторяющиеся исходные b в таблице по высоте и общие технические оговорки о неприменимых высотах. Раздел эпюры начинается с новой страницы, что исключает одинокий заголовок в конце предыдущей.
9. Excel гололёда: таблицы 12.3 и 12.4 показывают отдельно единицы высоты/диаметра и безразмерные коэффициенты, их назначение и ссылки на СП. Интерполяция μ1 защищена на крайних диаметрах. Ширины колонок рассчитаны для подробных полей. Лист «Эпюры нагрузок» содержит настоящую редактируемую диаграмму Excel (XY), связанную с формульной таблицей. Вкладываются соответствующие XML-ресурсы графика.
10. Существующие расчётные алгоритмы гололёда, снеговых схем, крановых и иных модулей сохранены, за исключением необходимой интеграции интерфейса и Excel-экспорта.

ПРОВЕРКА:
- GO111MODULE=off go test ./... -count=1: успешно.
- GOOS=windows GOARCH=amd64 go build -ldflags="-H=windowsgui -s -w": успешно.
- Экспорт Excel на диаметрах 5, 20, 70 мм: 1080 контрольных значений после пересчёта LibreOffice сравнены с Go-ядром, расхождений нет (допуск 1e-6).
- Четыре проверочные книги, включая совместный снег+гололёд: открытие и пересохранение LibreOffice, проверка XML и отсутствия формульных ошибок — успешно. Нативные диаграммы сохранены.
- Word: контрольный отчёт с ветром и гололёдом выведен в PDF и проверен на 4 страницах, включая эпюру и раздельные таблицы.

ОГРАНИЧЕНИЯ:
- В данной среде не было возможности запускать Windows GUI и проверить реальное поведение управления мышью; доступна компиляция Windows-EXE и структурные проверки.
- Прямой запуск в Microsoft Excel не проводился. Проверка OOXML, пересчёт формул и сохранность графика выполнены через LibreOffice.
- Нормативный коэффициент Cx=1,2 автоматизирован для проводов/тросов; для других элементов 1,2 лишь редактируемое предварительное значение, нормативный выбор по приложению В остаётся задачей инженера.
- Пульсационная составляющая ветра требует подтверждённых динамических данных и не рассчитывается автоматически; без этих данных рассматривается только средняя составляющая. Модуль не заменяет полный динамический расчёт по разделу 11.
- Для особо сложных территорий и гололёдных высот, где СП требует наблюдений, сохраняется необходимость подтверждённых метеоданных. Для ветра выше 300 м расчёт требует специального обоснования и блокируется ядром.
- Кнопка «Горные районы» открывает общий экран местности с существующими горными процедурами, а не отдельное маленькое диалоговое окно; повторного вычислительного ядра горного снега не создавалось.
- Прочие интерфейсные формы, не относящиеся к гололёду и снегу, не проходили визуальную проверку Windows.
