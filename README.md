# Ebala

Бесплатная инженерная программа для определения нагрузок и воздействий на строительные конструкции, с экспортом расчётов в Word и Excel.

## Скачать актуальную версию

**[Ebala 0.64 Beta](https://github.com/Mincka-mgn/Ebala/releases/tag/v0.64-beta.1)**

- **Ebala_0.64_Windows.zip** — готовая программа Windows x64 с картами, справочниками и ресурсами. Распакуйте архив целиком и запустите `Ebala_0.64.exe`.
- **Ebala_0.64_Sources.zip** — полные исходники, ресурсы и документация для независимого изучения.

Используйте **архивы на странице Releases**: в них включены необходимые ресурсы.

## Статус

Это бета-версия. Полный динамический расчёт ветровой нагрузки по собственным частотам пока не реализован; независимая нормативная и интерактивная проверка всех расчётных схем не завершена. Для ответственных инженерных решений сверяйте результаты с действующими нормативами.

Список изменений: [CHANGES_0.64.txt](CHANGES_0.64.txt). Архитектура и принципы: [PROJECT.md](PROJECT.md).
