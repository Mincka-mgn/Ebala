# Ebala 0.61 (бета) — ветер

## Запуск

Распакуйте **весь** Windows-архив в папку и запустите `Ebala_0.61.exe`. Сохраняйте рядом каталоги `WindData`, `Resources`, `Catalog`, `Databases`, `Maps`.

## Исходные данные

- Для здания введите длину **B** (вдоль конька), ширину **L** (поперёк конька), высоту конька **H**, подъём скатов **h**.
- Для отдельно стоящей стены введите длину **L** и высоту **H**; они показаны на рисунке забора.
- Базовое давление можно взять из района или ввести вручную. Коэффициент γf задаётся инженером; кнопка **?** объясняет нормативные значения.
- В блоке **«Учёт пульсации ветра»** по умолчанию стоит **«Не учитывать пульсацию»**. Это решение инженера, а не универсальное нормативное освобождение. Кнопка **«Про пульсации»** открывает справочник по категориям.

## Результаты

Первым показывается ветер **поперёк конька**. Можно переключать направление, поверхность, зону и альтернативные ветви. Наружные размеры и текст под схемой показывают длины зон. Два торца D/E подписаны рядом с соответствующими стенами.

Для кровли эпюра начинается на уровне карниза и заканчивается коньком. Сетка имеет не менее пяти интервалов по высоте и соблюдает введённый максимальный шаг. **Нагрузка для каждой нормативной кровельной зоны по существующему ядру определяется на эквивалентной высоте H и может быть постоянной по всей высоте ската.** Сетка нужна для отображения и проверки границ, она не вводит ненормативную функцию изменения давления.

## Отчёты

DOCX содержит рассчитанные ядром значения. XLSX содержит исходные данные, нормативные таблицы и собственные формулы для независимого пересчёта; в книге редактируемые H, h и шаг связаны с ординатами. При изменении топологии зон сформируйте новую книгу через Ebala.

## Ограничения

Не реализованы полная динамика с собственными частотами, пиковая нагрузка, специальные сооружения. Применимость корреляции пульсаций для наклонных скатов требует инженерной проверки. Отчёты проверены структурно, но запуск и работа на реальной Windows/Microsoft Office в данной среде не подтверждены. Подробности: `CHANGES_0.61.txt`, `QA_0.61.txt`.
