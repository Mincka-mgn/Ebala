Ebala 0.55 (бета)
Дата: 04.11.2026
Основа: Ebala 0.54; архитектурные решения PROJECT.md без изменения.

СТАТУС
- Версия 0.55 объявлена первой бета-версией действующих модулей без
  самостоятельного расчётного модуля ветровой нагрузки. К проектированию
  самостоятельного расчёта ветра вернёмся отдельным этапом.
- Климатические параметры ветра, необходимые при расчёте снега, а также
  ветровая составляющая гололёдного расчёта не отключались и не заменялись.

СДЕЛАНО
- Для круглого покрытия «сфера с конусом» (рисунок Б.15а) в Excel
  убрано ошибочное второе горизонтальное измерение «B»:
  на листе «Исходные данные» используется D — диаметр покрытия.
- На листе «Коэффициенты» для Б.15а больше нет фиктивной ширины B и
  вычисления характерного размера lc прямоугольного покрытия по (10.3),
  которое ранее возвращало 0 из пустого B.
- В Windows-форме при расчёте Б.15а больше не считывается скрытое
  поле ширины B; внутреннее значение согласуется с диаметром D.
- Для Б.15а сохранены необходимые связанные ячейки B4, B19, B21, B45,
  B46, B47: угол конуса, ce, ct, фактический диаметр. Excel вычисляет
  применимые производные коэффициенты независимо от чисел ядра.
- Лист «Формулы снега» для Б.15а больше не предлагает вычислять lc
  для прямоугольного плана. Для других форм покрытий формула сохранена.
- Сохранён утверждённый режим зоны 5: по умолчанию угол на сопряжении
  сферической/конической частей (α₂); альтернативный режим без изменения.
- Расчётные формулы остальных зон, в том числе сопряжения 2 и 4,
  не менялись. Искусственное сглаживание эпюр не вводилось.
- Заголовок программы теперь обозначает статус «(бета)».
- Добавлены три регрессионных теста Б.15а (исходные/формулы,
  независимость нагрузки от фиктивной ширины, реальный экспорт XLSX).
- Обновлена Windows GUI-сборка под номером 0.55.

ПРОВЕРКИ В СРЕДЕ СБОРКИ
- GO111MODULE=off go test ./... -count=1: PASS (полный набор).
- Три добавленных регрессионных теста Б.15а: PASS.
- Кросс-компиляция Windows x64: PASS (PE32+ GUI, без консоли).
- Контрольные общие XLSX: 2 снеговых + 1 гололёд + постоянные,
  временные, транспортные и крановые; отдельно 14 снеговых + 1 гололёд.
- Автоматический OOXML-анализ: 75 и 454 листа, 225993 и 1161875
  формул ячеек соответственно, 68 и 644 формулы диаграмм;
  отсутствующих ссылок, чужих индексов и обращений к навигационному
  листу из снеговых расчётов не найдено.

НЕ СДЕЛАНО
- Самостоятельный модуль ветровой нагрузки не вводился.
- Полная независимая нормативная ревизия всех схем приложения Б,
  а также полноценная проверка в Microsoft Office не входили
  в данное точечное исправление.

  что полная приёмка всех расчётов ещё не завершена.
