Ebala 0.44. Исправления по ТЗ к версии 0.43
===========================================

1. Сохранность расчётов и местность
- Смена местности меняет текущие климатические исходные данные, но не пересчитывает
  и не перезаписывает сохранённые схемы снега и гололёда.
- Каждая запись ведомости хранит собственные параметры и результат до повторного
  расчёта именно этой записи. В разных записях проекта допустима разная местность.
- Сохранение и загрузка файла проекта больше не требуют успешного вычисления
  незавершённых текущих расчётов.
- В рабочем модуле гололёда при неизвестном районе не подставляется нулевая
  нормативная толщина. По умолчанию доступен район IV (15 мм).
- Кнопка «Сбросить нагрузки» в модулях собственного веса, снега и гололёда
  очищает только рабочую форму. Сохранённая запись удаляется через ведомость.

2. Собственный вес
- Название из поля «Название конструкции» передаётся в название блока ведомости.
- При открытии сохранённого загружения его название восстанавливается.
  Переименование в ведомости синхронизируется с сохранённой конструкцией.
- Сохранённые слои копируются в независимый снимок, без общего изменяемого массива.
- Редактирование одной ячейки обновляет только соответствующую строку ListView
  вместо сброса всей таблицы и её прокрутки.
- Таблица слоёв растягивается по высоте при увеличении окна, итоговые строки
  и кнопки смещаются вниз.
- Эквивалентный коэффициент надёжности отображается с точностью 0,001;
  промежуточные расчёты сохраняют полную точность.

3. Word/Excel
- В общей ведомости каждый сохранённый пирог — отдельная таблица под собственным
  названием и со строкой «ИТОГО» для нормативной и расчётной нагрузок.
- В Word заголовки удерживаются с последующим содержимым, строки таблиц не
  разбиваются между страницами, шапки таблиц повторяются.
- Убран заключительный блок общих формул из Word-отчёта по собственному весу;
  подробные вычисления сохранены в Excel.
- Январская температура и применимость пониженной снеговой нагрузки описываются
  по фактическому значению: не указывается «не задана», если значение введено.
- Формат местности пропускает пустые элементы без лишних запятых.
- Формулировка сейсмичности: «Сейсмичность региона по карте А: 7 баллов»;
  карта и балльность подставляются по данным проекта.

4. Сейсмика
- Поиск откладывается на 400 мс после последнего символа, Enter запускает сразу.
- Вывод поиска ограничен первыми 250 совпадениями с указанием полного количества,
  чтобы список не блокировал окно при вводе короткой строки.

5. Снег
- Для однопролётной двускатной кровли добавлен флажок наличия ходовых мостиков
  или светоаэрационных устройств у конька.
- При включении флажка и уклоне 10–30 градусов формируется вариант 3 рисунка Б.1.
- При наличии второго пролёта флажок скрыт; индивидуальные схемы такого варианта
  при формировании пары не создаются.
- Ранее реализованные другие схемы снеговых нагрузок не перепроектировались:
  их полная отдельная нормативная ревизия отложена по решению пользователя.

6. Ветер
- Полноценный ветровой модуль не разрабатывался. Район Iа (0,17 кПа)
  уже имеется в справочнике и проверен отдельным тестом.

Проверено: полный набор Go-тестов, включая новые регрессии 0.44,
компиляция Windows amd64 и структурная проверка ZIP.

Ограничение: интерактивная работа окон на компьютере под Windows, Microsoft Word
и Microsoft Excel в этой среде не проверялись.

Исправление пакета сборки (2026-11-02): исполняемый файл пересобран с режимом подсистемы Windows GUI (-H=windowsgui) без консольного окна; исправлена версия выходного файла в build_windows.bat.
Поддержка Windows 7 в сборке на Go 1.23.2 отсутствует; требуется отдельная сборка на Go 1.20.x.
