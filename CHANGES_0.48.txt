Ebala 0.48 — выпуск по проверке версии 0.47
Дата: 03.11.2026

РЕАЛИЗОВАНО
1. «Сфера с конусом» (рисунок Б.15а) добавлена как отдельный тип снеговой кровли. Используется именно утверждённый PNG 1774×887 без векторной замены: Resources/SnowRoofs/snow_B15a_approved_geometry.png.
2. На вкладке исходных данных новая модель показывает утверждённую геометрию H, f, D, α, r; на вкладке результатов — полный исходный нормативный рисунок Б.15а.
3. Геометрия проверяет согласованность H, f, r и α. Введено явное допущение гладкого сопряжения конуса со сферическим участком и вертикальной касательной к сфере на внешней кромке. Неоднозначную геометрию программа не подгоняет молча.
4. Вычисляются равномерный по местным уклонам и пространственный варианты для Б.15а; во втором случае формируются шесть зон в полярной таблице и разрез 1–1, а также DOCX/XLSX.
5. Для купола с уклоном периферии более 60° убран общий запрет расчёта: на крутых частях μ=0. Предусмотрен подъём f>D/2 с наружным кольцом нулевой снеговой нагрузки.
6. Для конуса при α>=60° сохраняется возможность расчёта первого варианта с μ=0; общий отказ по наклону устранён.
7. У парапета исходный геометрический рисунок заменён на утверждённый чистый рисунок с размером h. Обе наклонные эпюры, включая дополнительную проверку, отображаются непрерывными отрезками вместо ступеней в интерфейсе и Word.
8. В эпюрах фонарей A/B/C восстановлены числовые подписи характерных ординат и вертикальные линии. Для двух соседних фонарей добавлено пояснение зон A/B/C с двумя пролётами.
9. В рабочем пути XLSX исправлено вычисление пространственных значений: новый тип использует свои фактические коэффициенты μ(r,β), а не формулу обычного конуса; для Б.15а записывается номер зоны.
10. Обновлены номер версии Windows-программы, инструкции и сборочный сценарий. Старые отложенные заглушки «Ветер» и самостоятельный «Перепад высот» не разрабатывались, существующий алгоритм соседних пролётов сохранён.

ОГРАНИЧЕНИЯ И ОГРАНИЧЕНИЯ ПРОВЕРКИ
- Новая схема Б.15а в этом выпуске охватывает только явно определённую геометрическую модель: гладкое сопряжение конуса и сферической части с вертикальной касательной к последней на внешнем краю. Произвольное значение угла α1 на опоре независимо не задаётся, поэтому все возможные физические купола не охвачены.
- Численное независимое подтверждение всех пространственных коэффициентов Б.15а на эталонном проекте и открытие документов непосредственно в Microsoft Office не проводились; перед применением в ответственном расчёте значения необходимо сопоставить с СП.
- Реальный интерактивный запуск Windows GUI (включая DPI 100/125/150%) в среде сборки недоступен. Исходный набор Go-тестов и Windows кросс-компиляция проверяют код и отчёты, но не заменяют пользовательскую проверку интерфейса.
- Совместимость файлов проектов старых выпусков и Windows 7 не проверялась.
