Ebala 0.47 — исправления после проверки 0.46
Дата: 03.11.2026

РЕАЛИЗОВАНО
1. В снеговом модуле разделены отдельные области отображения: слева поясняющая геометрическая/нормативная схема, справа расчётная эпюра. Список вариантов и детали расположены под правой эпюрой; рисунок не перекрывается списком и заголовками.
2. Перестройка компоновки результатов выполняется при изменении размера окна. Нижняя панель сохранения, сброса и экспорта привязана к нижнему краю; на вкладке исходных данных кнопка «Рассчитать» также закреплена внизу.
3. Список расчётных вариантов больше не перекрывается перерисовываемым графическим контролом; выбранная строка сохраняется при смене единиц измерения. Проверен алгоритм показа/скрытия на вкладках.
4. Верхняя стрелка на вкладке результатов возвращает на «Исходные данные» того же снегового расчёта. На вкладке исходных данных стрелка ведёт на главный экран.
5. Для эпюр с нулевой областью и последующим снегозаносом обозначается фактическая координата начала ненулевого участка, рассчитываемая по границам интервалов, а не предполагаемая равной середине кровли.
6. Для местного снегозаноса у парапета (Б.13) линия эпюры от максимума к обычной снеговой нагрузке строится непрерывной прямой и в окне программы, и в Word. Числовые консервативные интервалы расчётного ядра и детального Excel сохранены.
7. У покрытий с парапетом используется отдельная утверждённая геометрическая схема с высотой h. Расчёт Б.13 остаётся самостоятельным, код экспериментального отдельного перепада высот не используется как отдельный пользовательский модуль.
8. Для двух- и многопролётного сводчатого покрытия добавлен отдельный векторный рисунок с двумя соседними сводами; на экране результатов рисуется несколько сводов в соответствии с количеством пролётов.
9. Самостоятельная схема «Перепад высот» скрыта из списка снеговых схем. Её нормативный расчётный код оставлен нетронутым для последующей отдельной проработки; связанные алгоритмы двух соседних пролётов не удалены. Экспериментальный статус отмечен в коде.
10. Прототип самостоятельного модуля ветра остался отключённым и помеченным в исходниках как заглушка.
11. Номер версии обновлён до 0.47; сборка задаёт Windows GUI (PE Subsystem=2), без консольного окна.

СОЗНАТЕЛЬНО НЕ ИЗМЕНЯЛОСЬ
- Нормативные формулы и алгоритмы уже согласованных снеговых случаев (кроме графического представления непрерывной эпюры Б.13).
- Самостоятельный полный расчёт перепадов высот по Б.8 и модуль ветра: отложены.
- Совместимость с Windows 7: отдельная задача после основного релиза.
- Формат сохранённых проектов между разными выпусками: переносимость не гарантируется до релиза.

ОГРАНИЧЕНИЯ ПРОВЕРКИ
- Windows EXE собирается под Windows x64; интерактивная проверка GUI на настоящей Windows и с масштабированием DPI не выполнялась.
- Открытие DOCX/XLSX в настольных Microsoft Word/Excel не проверялось. Структура экспортных ZIP/XML и формирование файлов проверены программно.
- Сохраняется дискретный (консервативный) расчёт интервалов Б.13 для аудита в Excel; только отображаемая нормативная эпюра непрерывна.
